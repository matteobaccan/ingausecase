# 0DIN AI Scanner

## Introduzione

Piattaforma open source per valutare LLM e app IA con centosettantanove probe di sicurezza allineati a OWASP LLM Top 10.

## Funzionalità principali

- 0DIN AI Scanner è una piattaforma open source per valutare LLM e app IA: centosettantanove probe di sicurezza allineati a OWASP LLM Top 10, scansiona API e app browser, scoring Attack Success Rate, report PDF e integrazione SIEM.
