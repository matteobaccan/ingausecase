# Next.js

## Introduzione

Framework React open source per applicazioni web full-stack, sviluppato da Vercel, tra i più usati nel mondo per frontend e server-side rendering.

## Funzionalità principali

- Next.js ha rilasciato le versioni 16.2.6 e 15.5.18 con importanti fix di sicurezza: vulnerabilità multiple tra severità alta, moderata e bassa, inclusa una upstream di React, con aggiornamento fortemente raccomandato.
