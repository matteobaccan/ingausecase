# MCP Financial Datasets

## Introduzione

Server MCP che espone dati finanziari reali (azioni, prezzi crypto, bilanci societari) agli agenti come Claude Code. Autenticazione via OAuth.

## Funzionalità principali

- Il server MCP Financial Datasets collega Claude Code a diciassettemila azioni, prezzi crypto e bilanci societari: con un comando e sessanta secondi, autenticandosi via OAuth, si ottengono P/E ratio, market cap, income statement e cash flow in tempo reale.
