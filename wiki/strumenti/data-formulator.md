# Data-Formulator

## Introduzione

Strumento di [[microsoft]] per l'analisi dati via agente: si collegano CSV, Postgres, BigQuery o URL live e si costruiscono grafici mescolando drag-and-drop e linguaggio naturale.

## Funzionalità principali

- L'agente scrive SQL e trasformazioni sotto, restituisce un grafico modificabile, permette di ancorare risultati puliti, creare branch per esplorare varianti e connettere dati live con auto-refresh; si porta la propria chiave API e si esegue in locale.
