# agent-skills

## Introduzione

Ventitré skill strutturate di Addy Osmani che replicano i processi di Google Engineering, con sette comandi slash.

## Funzionalità principali

- agent-skills di Addy Osmani offre skill di livello senior per agenti AI con controlli di qualità integrati: gli agenti sviluppano seguendo sempre lo stesso processo senza deviazioni; 45000 stelle.
- agent-skills di Addy Osmani raccoglie skill Claude Code da ingegneri Google: API design, code review, debugging, CI/CD e frontend optimization, pronte per i workflow di sviluppo.
- Agent Skills di Addy Osmani: ventitré skill strutturate che replicano i processi di Google Engineering, con sette comandi slash per il ciclo completo (spec, plan, build, test, review, simplify, ship); compatibile con Claude Code, Cursor, Copilot e Gemini CLI; MIT, cinquantuno punto cinque mila stelle.

- **2025-12-29** — La guida completa alle Claude Code Skills spiega come trasformare l'assistente generico in un esperto del dominio specifico, capace di automatizzare workflow complessi e accelerare i processi di sviluppo, e non solo nello sviluppo software: l'idea è che le Skills siano la chiave per adattare lo strumento a qualunque ambito professionale.
- **2026-03-07** — Lo skill-creator di Claude Code viene ripensato e ora include evals automatici, benchmark, A/B testing cieco e trigger tuning: in pratica le skill possono testarsi, misurarsi e migliorarsi da sole. Il ragionamento dietro l'aggiornamento è che il valore dell'AI non stia solo nel modello intelligente ma nel costruire skill personalizzate sopra il modello, e che con questi strumenti creare skill di valore diventi accessibile anche a chi non è ingegnere.
- **2026-06-22** — Due skill open source per Claude Code portano nel terminale il lavoro che di solito richiede Ahrefs, Semrush, un copywriter e mezza giornata di checklist: Claude SEO, che al 22 giugno 2026 raccoglie 9.461 stelle su GitHub, e Claude Blog, ferma a 1.126 stelle ma in crescita rapida. Le ha costruite Daniel Agrici, che si definisce AI Marketing Systems Architect e co-fondatore di Rankenstein, con licenza MIT e zero abbonamenti, e un sito nato il 23 marzo 2026 e gestito interamente con questo flusso mostra secondo il suo autore una curva di clic e impressioni in crescita costante nei primi tre mesi.
- **2026-07-21** — Record a skill aggiunge la terza via per creare una skill: invece di scrivere i file a mano o descrivere il processo in conversazione, si registra lo schermo mentre si esegue il compito una volta sola — click, testo digitato e narrazione vocale — e Claude ricava da sé la procedura, salvandola con un nome breve come /file-expenses; la funzione vive in [[claude-cowork]] ed è riservata ai piani Pro, Max e Team.
- **2026-09-29** — Google porta lo stesso formato in Gemini: fra le quattro strade per creare una Skill c'è il caricamento di un file SKILL.md o di una cartella che lo contiene, lo stesso nome usato dalle skill di Claude Code, ma il comportamento di una skill scritta per Claude va verificato perché le due piattaforme supportano strumenti e file diversi.
- **2026-10-23** — Anthropic dona lo standard Agent Skills all'Agentic AI Foundation: passano alla fondazione il nome, il logo, l'organizzazione GitHub e il dominio agentskills.io, mentre le skill scritte dagli sviluppatori restano dei rispettivi autori. Anthropic dichiara un milione di skill pubblicate e quasi 280 milioni di installazioni, più di 70 piattaforme che leggono il formato, e una roadmap con release versionate, un processo formale per le modifiche e linee guida di sicurezza.

- **2026-10-23** — Nello stesso giorno l'AAIF accoglie altri tre progetti e passa da 3 a 10: Open Responses di OpenAI, OpenEnv di Hugging Face e OpenSandbox di Alibaba, accanto a MCP, goose, AGENTS.md, A2A, Agent Router e agentgateway.

- **2026-10-23** — Google Cloud propone SKILL.md come terzo dei tre file per gli agenti di coding, quello con le procedure caricate solo quando il compito le richiede: il repository google/skills, presentato al Cloud Next di aprile con 13 skill, ne conta 21.503 stelle e si installa con `npx skills install github.com/google/skills`.
