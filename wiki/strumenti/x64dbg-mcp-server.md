# x64dbg-mcp-server

x64dbg-mcp-server trasforma il debugger x64dbg in un servizio controllabile da Claude o altri assistenti IA. Include oltre 80 API per il controllo del debugger: memoria, breakpoint, registri, rilevamento OEP. Scritto in Zig, non ha dipendenze esterne.

**Caratteristiche principali:**
- 80+ API per il controllo del debugger
- Supporto memoria, breakpoint, registri
- Rilevamento OEP (Original Entry Point)
- Scritto in Zig, zero dipendenze esterne
- Integrabile con Claude e altri assistenti IA
