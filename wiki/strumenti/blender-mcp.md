# Blender MCP

## Introduzione

Server MCP che collega modelli IA al software di modellazione 3D Blender, permettendo di generare scene tridimensionali complete da prompt in linguaggio naturale.

## Funzionalità principali

- Blender MCP collegato a Kimi K3 trasforma descrizioni in linguaggio naturale in scene tridimensionali complete: terreno, edifici, illuminazione, animazioni e script Python, tutto editabile.
