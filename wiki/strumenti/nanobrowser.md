# NanoBrowser

## Introduzione

Plugin Chrome open source che automatizza completamente il browser in linguaggio naturale, funziona anche con modelli locali via Ollama.

## Funzionalità principali

- NanoBrowser è un plugin Chrome open source che automatizza il browser: legge le pagine, clicca pulsanti, estrae dati e compila form in linguaggio naturale; tredici mila stelle in pochi giorni; funziona anche con modelli locali via Ollama.
