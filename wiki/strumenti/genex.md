# Genex

## Introduzione

Applicazione desktop open source per costruire giochi con intelligenza artificiale, presentata il 6 ottobre 2026.

## Funzionalità principali

- Supporta modelli locali oppure abbonamenti Claude Code e ChatGPT.
- Integra Three.js, Blender e Meshy, con plugin Unity e Unreal in arrivo.
