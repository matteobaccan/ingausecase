# Interactions API

## Introduzione

API pubblica di Google, interfaccia primaria per modelli Gemini e agenti, con esecuzione asincrona.

## Funzionalità principali

- La Interactions API di Google è ora disponibile pubblicamente come interfaccia primaria per modelli Gemini e agenti: con Antigravity Agent, sandbox Linux isolato, generazione immagini con Nano Banana, musica con Lyria 3 ed esecuzione asincrona (background uguale true).
