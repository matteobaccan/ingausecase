# spec-kit

## Introduzione

Tool di GitHub che trasforma una idea in una specifica strutturata con sei comandi, facendo lavorare l'agente sulla specifica invece che sul codice, compatibile con i principali agenti di coding.

## Funzionalità principali

- GitHub ha rilasciato spec-kit, con 92.000 stelle in pochi giorni: sei comandi trasformano l'idea in una specifica strutturata e l'agente lavora sulla specifica, funzionando con Claude Code, Copilot, Cursor, Codex, Gemini e venticinque agenti in più; l'IA esegue una specifica invece di scrivere codice.
- GitHub ha rilasciato spec-kit con 92.000 stelle: sei comandi (Constitution, Specify, Clarify, Plan, Tasks, Implement) trasformano un'idea in specifica eseguibile; l'agente non lavora più sul codice ma sulla specifica, funziona con Claude Code, Copilot, Cursor, Codex, Gemini e venticinque agenti in più.
- GitHub ha pubblicato Spec-Kit: 95.000 stelle in pochi giorni e 8.300 fork; sei comandi trasformano un'idea in specifica strutturata prima di scrivere codice, risolvendo il problema di interpretare ciò che gli agenti vogliono: prima pensi, poi costruisci.
