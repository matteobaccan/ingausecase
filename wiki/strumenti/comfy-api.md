# Comfy API

## Introduzione

API lanciata da [[comfyui]] per trasformare un workflow in un endpoint distribuibile. [Fonte: raw/puntate/ainews20261001.md]

## Funzionalità principali

- Punta l'API a un file JSON del workflow e gestisce tutto: risolve custom node, modelli, LoRA e dipendenze Python. [Fonte: raw/puntate/ainews20261001.md]
- Blocca tutto in una build versionata e crea un rilascio immutabile. [Fonte: raw/puntate/ainews20261001.md]
- Deploy come endpoint autoscaling su RTX PRO 6000, H100, H200 o B200. [Fonte: raw/puntate/ainews20261001.md]
