# UE5 MCP Tools

## Introduzione

Set open source di circa 520 tool MCP per controllare Unreal Engine 5 tramite agenti AI (Niagara, MetaHumans, Sequencer, PCG, source control).

## Funzionalità principali

- Sono usciti 520 MCP tools per Unreal Engine 5: coprono Niagara, MetaHumans, Sequencer, virtual production, PCG e source control, permettendo all'agente di controllare praticamente tutto UE5, open source.
