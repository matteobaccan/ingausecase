# claude-code-router

## Introduzione

Router con trentacinquemila stelle con Kimi K3 integrato nativamente: un click per API o subscription, failover automatico e cache a 0,30 dollari per milione.

## Funzionalità principali

- claude-code-router ha trentacinquemila stelle: Kimi K3 integrato nativamente, un click per API o subscription, failover automatico, cache a zero virgola trenta dollari per milione di token e proxy opzionale.
- Moonshot ora sponsorizza claude-code-router: gli setup esistenti rimangono intatti, Kimi K3 si connette con un click, con preset integrati, failover automatico e caching a 0,30 dollari per milione di token.
