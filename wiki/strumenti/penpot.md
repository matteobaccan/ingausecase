# Penpot

## Introduzione

Strumento open source di design UI/UX, alternativa a Figma.

## Funzionalità principali

- Penpot è stato indicato come alternativa open source gratuita a Figma per il design.

## Timeline delle notizie

- **2026-06-01** — Penpot è stato indicato come alternativa open source gratuita a Figma per il design.
- **2026-10-13** — Penpot è l'alternativa open source più citata a Figma: 61.014 stelle su GitHub e versione 2.18.3 del 6 ottobre, licenza MPL-2.0, self-hosting con Docker o Kubernetes, piano Professional gratuito con otto membri per team, 10 GB e sette giorni di cronologia, e un server MCP con cui un agente legge e modifica componenti, token, pagine e livelli del file aperto.
