# DaVinci Resolve

## Introduzione

DaVinci Resolve è un software di video editing che ora supporta l'integrazione diretta con Claude o ChatGPT via MCP.

## Funzionalità principali

- Integrazione diretta con Claude o ChatGPT via Model Context Protocol.
- Editing e color grading automatico su richiesta in linguaggio naturale.
