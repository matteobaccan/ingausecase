# DaVinci Resolve

## Introduzione

DaVinci Resolve è un software di video editing che ora supporta l'integrazione diretta con Claude o ChatGPT via MCP. [Fonte: raw/puntate/ainews20260909.md]

- Integrazione diretta con Claude o ChatGPT via Model Context Protocol. [Fonte: raw/puntate/ainews20260909.md]
