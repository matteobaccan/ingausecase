# Warp Terminal

## Introduzione

Terminale moderno open source di sette megabyte pensato per programmatori AI, con editor integrato, Git e agenti.

## Funzionalità principali

- Warp Terminal pesa sette megabyte, ha editor integrato, Git, agenti e preview web, senza telemetria né registrazione; disponibile per Windows, macOS e Linux, gratuito e open source.
