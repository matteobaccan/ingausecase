# MMAE

## Introduzione

Primo benchmark per l'editing audio: modifica file esistenti seguendo istruzioni in linguaggio naturale.

## Funzionalità principali

- MMAE (Tencent + università) modifica file audio esistenti seguendo istruzioni in linguaggio naturale, cambiando solo ciò che serve: duemila campioni e oltre diciassettemila criteri di valutazione; i modelli attuali sono sotto il cinque percento di precisione.
