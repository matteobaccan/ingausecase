# Jevbox

## Introduzione

Drive documentale che si organizza da solo: carica un file e [[jev]] lo categorizza, con ricerca gerarchica che sceglie prima la cartella, poi il documento, poi la sezione. Ogni risposta cita pagina e sezione, i permessi si applicano anche al retrieval ed è open source con server MCP integrato.

## Funzionalità principali

- La ricerca è gerarchica: il sistema sceglie la cartella, poi il documento, poi la sezione, e ogni risposta cita pagina e sezione. [Fonte: raw/puntate/ainews20261003.md]
- I permessi si applicano anche al retrieval ed è distribuito open source con server MCP integrato. [Fonte: raw/puntate/ainews20261003.md]
