# Crawl4AI

## Introduzione

Libreria open source con settantamila stelle su GitHub che converte pagine web in Markdown pulito per LLM, con caching e async integrate.

## Funzionalità principali

- Crawl4AI è un'alternativa open source a Firecrawl: scraping di siti web in markdown o JSON strutturato, gestione di JavaScript e SPA, nessun account o costo, con sessantasette punto otto K stelle su GitHub.
- Crawl4AI ha settantamila stelle su GitHub: converte pagine web in Markdown pulito per LLM, rimuove il rumore, preserva tabelle e codice, zero API key, con caching e async per scavare senza ban.
