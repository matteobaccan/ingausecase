# Hound

## Introduzione

Server MCP gratuito per navigare il web senza chiavi API: fetch, search, crawl e screenshot, tutto keyless con dieci backend di ricerca.

## Funzionalità principali

- Hound è un server MCP gratuito per navigare il web senza chiavi API: fetch, search, crawl e screenshot keyless, estensione nativa per Pi, dieci backend di ricerca in parallelo, recupero automatico dall'Internet Archive per pagine morte, fetch anti-bot e OCR automatico per PDF, zero costi mensili.
