# Claude Code Harness

## Introduzione

Strumento open source e gratuito che risolve il problema principale degli AI coding tools: obbliga Claude a seguire un loop strutturato (pianifica, lavora, rivede, rilascia) con revisione automatica del codice.

## Funzionalità principali

- È stato costruito Claude Code Harness, open source e gratuito, che obbliga Claude a seguire un loop strutturato - pianifica, lavora, rivede il proprio codice, rilascia - con revisione automatica su sicurezza, performance, qualità e accessibilità, evitando che l'agente modifichi nove file e dica 'fatto' lasciando qualcosa di rotto.
