# Olmo-core 3

## Introduzione

Infrastruttura di training aperta dell'Allen Institute per modelli mixture-of-experts di grandi dimensioni: è il sistema core dietro la prossima generazione di Olmo ed è progettato per scalare fino a trilioni di parametri.

## Funzionalità principali

- È un framework di training open per modelli mixture-of-experts pensato per scalare fino alla fascia dei trilioni di parametri.
