# gemini-web2api

## Introduzione

Script Python (400 stelle in due giorni) che trasforma la versione web di Gemini in un server compatibile OpenAI API, con streaming, function calling e tool calling, Docker one-click.

## Funzionalità principali

- gemini-web2api (scritto in Python, 400 stelle in due giorni) trasforma la versione web di Gemini in un server compatibile con l'API OpenAI: nessuna dipendenza esterna, supporto streaming, function calling e tool calling, modelli Flash, Flash Thinking, Pro, Auto e Lite, Docker one-click, con un risparmio da 20 a 50 dollari al mese.
