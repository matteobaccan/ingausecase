# liquid-audio

## Introduzione

Repo open source per modelli LFM speech-to-speech state of the art, end-to-end, con supporto al fine-tuning.

## Funzionalità principali

- liquid-audio è il repo open source per modelli LFM speech-to-speech state of the art, end-to-end, ora con supporto al fine-tuning: basta un solo modello invece di cablare tre modelli separati per audio-to-text, text-to-audio o text-to-text.
