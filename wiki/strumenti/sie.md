# SIE

## Introduzione

Motore open source che carica e scarica modelli dinamicamente in base al traffico: un solo processo, una sola GPU, ottantacinque modelli dietro una API. Apache due virgola zero.

## Funzionalità principali

- SIE riduce del settantacinque percento i costi dei server: invece di un server per modello, carica e scarica i modelli dinamicamente in base al traffico, con un solo processo e una sola GPU; ottantacinque modelli dietro una API, licenza Apache due virgola zero.
