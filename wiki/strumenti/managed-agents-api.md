# Managed Agents API

## Introduzione

API di Anthropic per integrare agenti gestiti, alternativa a Cowork per i template verticali finanza.

## Funzionalità principali

- Managed Agents API di Anthropic permette di integrare i team di agenti finanza (investment banking, ricerca azionaria, private equity, asset management) oltre che caricarli in Cowork.
