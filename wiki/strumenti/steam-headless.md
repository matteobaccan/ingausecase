# Steam Headless

## Introduzione

Container Docker di Josh Sunnex che trasforma qualsiasi PC in cloud gaming personale, alternativa a GeForce NOW.

## Funzionalità principali

- Steam Headless di Josh Sunnex è un container Docker che trasforma qualsiasi PC in cloud gaming personale: nessun cap orario o costo mensile, GPU NVIDIA/AMD/Intel, streaming via Moonlight, Steam Link o browser; alternativa gratuita a GeForce NOW.
