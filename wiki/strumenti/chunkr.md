# Chunkr

## Introduzione

Strumento self-hosted via Docker Compose che converte PDF, PPT, Word e immagini in chunk strutturati per pipeline RAG, con OCR e analisi layout.

## Funzionalità principali

- Converte PDF, PPT, Word e immagini in chunk strutturati per pipeline RAG: analisi layout con OCR, output HTML e Markdown, processing con modelli vision-language, self-hosted via Docker Compose.
