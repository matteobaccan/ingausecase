# SAM3DBody-cpp

## Introduzione

Motore C++ per pose estimation 3D real-time con 70 punti articolari di corpo e mani più mesh tridimensionale, zero Python e API C minimale.

## Funzionalità principali

- SAM3DBody-cpp è un motore C++ per pose estimation 3D real-time: 70 punti articolari di corpo e mani più mesh tridimensionale, input video da camera, zero Python e API C minimale per integrazione cross-language, pensato per robotica e motion capture.
