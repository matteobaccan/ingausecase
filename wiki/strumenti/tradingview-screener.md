# TradingView-Screener

## Introduzione

Strumento che si collega direttamente alle API ufficiali di [[tradingview]] per scaricare dati finanziari: niente crawler, niente abbonamenti.

## Funzionalità principali

- Tremila campi, settanta paesi, azioni, cripto, forex e futures.
- Si collega direttamente alle API ufficiali TradingView.
- Query SQL e ritorno come pandas DataFrame, pronto per backtest.
