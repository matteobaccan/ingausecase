# Packagist

## Introduzione

Registry ufficiale dei pacchetti PHP, ha rimosso gli otto pacchetti infetti dall'attacco di maggio 2026.

## Funzionalità principali

- Packagist ha rimosso gli otto pacchetti PHP confermati infetti nell'attacco supply chain (oltre 700 repository GitHub compromessi), ma le versioni auto-aggiornanti potrebbero tornare.
