# Claude Ads

## Introduzione

Skill gratuita per Claude Code che esegue centonovanta controlli di audit sulle piattaforme pubblicitarie.

## Funzionalità principali

- Claude Ads è una skill gratuita per Claude Code che esegue centonovanta controlli di audit su Google, Meta, YouTube, LinkedIn, TikTok e Microsoft Ads con sei subagent paralleli, consolidando il tutto in un unico Ads Health Score classificato per impatto sul fatturato.
