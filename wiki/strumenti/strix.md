# Strix

## Introduzione

Framework di sicurezza che simula attacchi reali contro il codice: esegue l'app in Docker, testa XSS e SQL injection via proxy HTTP e genera patch automatiche.

## Funzionalità principali

- Framework di sicurezza che simula attacchi reali: gira l'app in Docker, usa proxy HTTP per testare XSS e SQL injection, scrive exploit funzionanti con PoC completi, genera patch automatiche e apre PR. Si integra in CI/CD.
