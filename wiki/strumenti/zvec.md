# Zvec

## Introduzione

Database vettoriale embedded open source di Alibaba, gira dentro l'app senza server; ricerca miliardi di vettori in millisecondi.

## Strumenti correlati

- [[zg]]

## Funzionalità principali

- Alibaba ha aperto il codice di Zvec, un database vettoriale che gira direttamente dentro la tua app senza server né configurazione: ricerca miliardi di vettori in millisecondi, testato in produzione dentro Alibaba, installabile con pip install zvec e senza bollette da 200 dollari al mese.
- Zvec è comparso su GitHub come database vettoriale in-process di Alibaba: esecuzione dentro l'applicazione, nessun server, ideale per RAG locale, installazione con un singolo comando.
