# Thermo-Nuclear Code Quality Review

## Introduzione

Skill di code review estrema: un set di regole per Cursor che applica standard qualitativi altissimi al codice prodotto dagli agenti.

## Funzionalità principali

- Semplificazione strutturale prioritaria.
- Limite rosso a mille righe per file.
- Rifiuto della crescita a spaghetti.
- Individua problemi di struttura, non di stile.
