# Skill Weaver

## Introduzione

Sistema che decompone query complesse in sotto-task atomici e costruisce piani eseguibili recuperando le skill giuste.

## Funzionalità principali

- Skill Weaver decompone query complesse in sotto-task atomici, recupera le skill giuste per ognuno e costruisce un piano eseguibile; arriva con CompSkillBench: trecento query composizionali su duemiladuecento skill reali, perché le task reali raramente mappano su una singola skill.
