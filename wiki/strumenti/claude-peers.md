# claude-peers

## Introduzione

Strumento che fa messaggiare tra loro più sessioni di Claude Code con broker locale e SQLite.

## Funzionalità principali

- claude-peers fa messaggiare tra loro cinque sessioni di Claude Code su progetti diversi: scoperta automatica, messaggi istantanei, condivisione di contesto e coordinamento, con broker locale, SQLite e un server MCP per sessione, tutto in locale.
