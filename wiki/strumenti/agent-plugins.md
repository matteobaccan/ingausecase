# Agent Plugins

## Introduzione

Standard aperto di OpenAI per pacchettizzare Agent Skills, sviluppato con AWS, Cursor, GitHub, VS Code e Vercel, con supporto a configurazioni MCP server condivise.

## Funzionalità principali

- Agent Plugins e' lo standard aperto di OpenAI sviluppato con AWS, Cursor, GitHub, Visual Studio Code e Vercel: pacchettizza Agent Skills e supporta configurazioni MCP server in formato condiviso.
- OpenAI, Microsoft, Google, Cursor, Vercel e GitHub hanno standardizzato Agent Plugins: un unico formato per skills e server MCP con file plugin dot json, cartella skills e file mcp dot json, nessuna configurazione extra.
