# ComfyTV

## Introduzione

Estensione infinite canvas per ComfyUI con plugin, subgraph e workflow riutilizzabili.

## Funzionalità principali

- ComfyTV porta l'infinite canvas a ComfyUI: integrazione completa con plugin e subgraph, workflow riutilizzabili, propagazione automatica degli output e generazione locale senza API esterne; zero dipendenze Python aggiuntive.
