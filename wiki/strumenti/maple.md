# Maple

## Introduzione

Strumento che trasforma dati di telemetria in una mappa interattiva dei servizi in tempo reale.

## Funzionalità principali

- Maple trasforma i dati di telemetria in una mappa di servizi interattiva in tempo reale: visualizzi API, database e code di messaggistica con metriche live su latenze e tassi di errore; architettura basata su Effect e server MCP integrato.
