# ADR

## Introduzione

Framework open source di Uber per il monitoraggio e la sicurezza degli agenti IA in ambiente enterprise. Includee trecento task di sicurezza e supporta centotrentatré server MCP.

## Funzionalità principali

- ADR, framework open source di Uber, include trecento task di sicurezza, supporta centotrentatré server MCP e funziona su macOS, Linux e Windows; sviluppato in collaborazione con MLSys 2026.
