# Antigravity-Manager

## Introduzione

Tool per gestire più account Gemini e Claude con rotazione automatica a fine quota o su rate limit; endpoint locale OpenAI/Anthropic-compatible, Tauri v2 più Rust.

## Funzionalità principali

- Antigravity-Manager è un tool per gestire più account Gemini e Claude: rotazione automatica quando la quota finisce o scatta il rate limit, endpoint locale compatibile con OpenAI e Anthropic, costruito con Tauri v2 e Rust, interfaccia grafica e supporto Docker, pensato per chi usa Claude Code o setup intensivi.
