# OSIRIS

## Introduzione

Piattaforma open source tipo Palantir: globo 3D real-time con aerei, satelliti, CCTV, disastri e toolkit OSINT.

## Funzionalità principali

- OSIRIS è un Palantir gratuito installabile in un comando: globo 3D nel browser in tempo reale con oltre diecimila aerei in volo, oltre duemila satelliti, telecamere CCTV globali, incendi, terremoti, traffico marittimo e tredici zone di conflitto attive; include toolkit OSINT (port scanner, DNS, WHOIS, analisi domini), licenza MIT, docker compose up, e la maggior parte delle fonti funziona senza API key.
