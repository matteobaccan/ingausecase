# Gemini CLI

## Introduzione

CLI di coding di Google, orchestrabile insieme a Claude Code e Codex via rmux.

## Funzionalità principali

- Gemini CLI è orchestrato da Claude Code sullo stesso terminale tramite rmux, la riscrittura Rust di tmux pensata per agenti.

- **2026-06-23** — Gemini CLI è orchestrato da Claude Code sullo stesso terminale tramite rmux, la riscrittura Rust di tmux pensata per agenti. [Fonte: raw/puntate/ainews20260623.md]

- **2026-09-21** — È tra i quattro agenti vulnerabili a Plugin4Shell, con un percorso diverso dagli altri: il fetch sullo SHA seguito da un checkout di FETCH_HEAD finisce sul ramo sbagliato se il repository ha un ramo predefinito con quel nome.
