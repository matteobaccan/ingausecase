# Violin

## Introduzione

Skill open source (MIT) per traduzione video che combina ASR, traduzione LLM e TTS in un unico pipeline, con chat col video.

## Funzionalità principali

- Violin è uno skill open source per traduzione video: combina riconoscimento vocale, traduzione LLM e sintesi vocale in un unico pipeline, con ASR e TTS multilingua di alta qualità, personalizzazione di traduzione e voce, chat col video, supporto web app, CLI e agent skill, licenza MIT.
- Violin su GitHub fa traduzione e doppiaggio automatico video: trentatré lingue supportate, con Whisper Large v3 per il riconoscimento, DeepSeek V4 Pro per la traduzione e Cartesia Sonic 3 per la sintesi vocale, più Q&A diretto sul contenuto video.
