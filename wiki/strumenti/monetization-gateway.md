# Monetization Gateway

## Introduzione

Gateway di Cloudflare per addebitare l'accesso a pagine web, dataset, API o tool MCP, con pagamenti in stablecoin via protocollo X402.

## Funzionalità principali

- Lista d'attesa aperta: permette di addebitare per qualsiasi pagina web, dataset, API o tool MCP dietro Cloudflare; i pagamenti si regolano in stablecoin tramite il protocollo aperto X402.
