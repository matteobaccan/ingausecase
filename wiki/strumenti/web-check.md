# Web-Check

## Introduzione

Strumento OSINT open source che analizza qualsiasi sito web: IP, SSL, DNS, cookie, porte, traceroute e altro.

## Funzionalità principali

- Web-Check fa analisi on-demand di qualsiasi sito web: IP, SSL, DNS, cookie, header, porte aperte, traceroute, performance, tracker e carbon footprint; deploy via Netlify, Vercel o Docker.
