# tgrep

## Introduzione

Strumento di [[microsoft]] per ricerche in grandi code base, con supporto client-server. Da 7 a 50 volte più veloce di ripgrep e ugrep secondo i benchmark. Scritto in Rust, sotto licenza MIT, rispetta gitignore ed è già integrato in GitHub Copilot CLI.

## Funzionalità principali

- Ricerca ultra-rapida in grandi code base: 7-50x più veloce di ripgrep e ugrep.
- Supporto client-server.
- Rispetta gitignore.
- Integrazione in GitHub Copilot CLI.

## Installazione e uso

- Scritto in Rust, licenza MIT, open source.
