# Chrome.html-in-canvas

## Introduzione

Progetto Google per il rendering di DOM live come texture 3D, con CSS completo, flexbox, grid e animazioni funzionanti.

## Funzionalità principali

- Chrome.html-in-canvas di Google rende il DOM live come texture 3D: CSS completo, flexbox, grid e animazioni, testo selezionabile e input funzionanti; qualcuno ha già costruito un plugin per trasformare UI in tessuto simulato.
