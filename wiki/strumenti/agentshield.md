# AgentShield

## Introduzione

Componente del sistema ECC dedicato a scansionare vulnerabilità e segreti esposti negli ambienti degli agenti IA. È incluso nella suite di skill di ECC.

## Funzionalità principali

- AgentShield fa parte del sistema open source vincitore dell'hackathon Anthropic-Cerebral Valley: fa security scan tra 55 agenti specializzati, 208 skill, 72 slash command, dashboard GUI, memoria persistente cross-sessione, 1.282 test con 98% coverage, dopo dieci mesi di uso quotidiano prima del rilascio.
- ECC include AgentShield per scansionare vulnerabilità e segreti esposti, all'interno delle sue duecentosessantadue skill pubbliche per coding, ricerca, sicurezza e flussi enterprise.
