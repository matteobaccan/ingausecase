# Retrieval Harness

## Introduzione

Pipeline persistente per retrieval agentivo: connette data source, indicizza knowledge base ed espone tool simili a filesystem per il crawling autonomo degli agenti.

## Funzionalità principali

- Pipeline persistente per retrieval agentivo: connette data source, indicizza knowledge base, espone tool simili a filesystem con search semantico, keyword, regex grep e file search. Si integra con qualsiasi agente per crawling autonomo.
