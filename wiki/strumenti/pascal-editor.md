# Pascal Editor

## Introduzione

Editor 3D open source per edifici completo nel browser (WebGPU e React Three Fiber), killer di Revit e AutoCAD, con integrazione IA via MCP. Ventunomila stelle.

## Funzionalità principali

- Editor 3D per edifici in browser, niente AutoCAD o Revit: built with React Three Fiber e WebGPU, hierarchy building completa, rendering GPU e undo-redo integrato. Open source.
- Pascal Editor e' un killer open source di Revit e AutoCAD: editor tre D edifici completo nel browser con WebGPU e React Three Fiber, gerarchia Site-Building-Level-Wall-Slab-Ceiling-Roof-Zone-Item, tool interattivi, validazione spaziale real-time e integrazione IA via MCP; ventunomila stelle.
