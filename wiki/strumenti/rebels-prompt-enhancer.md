# Rebels Prompt Enhancer

## Introduzione

Nodo personalizzato per ComfyUI che espande automaticamente i prompt brevi in descrizioni dettagliate, trovato su GitHub.

## Funzionalità principali

- Su GitHub è stato trovato Rebels Prompt Enhancer, un nodo per ComfyUI che espande automaticamente i prompt: gira su GPU limitate, libera RAM dopo l'uso, funziona offline con zero costi API ed è compatibile anche con la generazione video.
