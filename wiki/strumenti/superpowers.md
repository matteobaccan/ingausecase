# Superpowers

## Introduzione

Plugin che trasforma Claude Code, Codex e Cursor in senior developer forzando brainstorming prima del codice e applicando TDD senza eccezioni. Oltre novantaquattromila stelle.

## Funzionalità principali

- Superpowers supera novantaquattromila stelle su GitHub: trasforma Claude Code, Codex e Cursor in senior developer forzando brainstorming prima del codice e applicando TDD senza eccezioni.

## Timeline delle notizie

- **2026-02-04** — Superpowers, framework agentico open source di Jesse Vincent per [[claude-code]], supera le 170.000 stelle su GitHub e impone un workflow in sette fasi: brainstorming socratico, git worktree isolati, piani di task da 2-5 minuti, sub-agenti paralleli, TDD con ciclo RED-GREEN-REFACTOR, code review sistematica e chiusura del branch. La versione 5.0.7 è l'ultima release stabile e il plugin è nel marketplace Anthropic dal 15 gennaio 2026, con supporto a sei runtime tra cui Cursor, Gemini CLI e GitHub Copilot CLI.
