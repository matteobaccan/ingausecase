# Hyperframes

## Introduzione

Framework video open source di HeyGen, alternativa a Remotion senza React né JSX, renderizza MP4 da HTML.

## Funzionalità principali

- Hyperframes è stato rilasciato open source da HeyGen: fa tutto ciò che fa Remotion senza React, JSX o nuovi formati; l'agente scrive HTML e il framework renderizza MP4, con supporto GSAP, Lottie e Three.js; lo stesso HTML produce sempre lo stesso file.
- HyperFrames ha reso open source dieci template frame.md per migliorare i tuoi video, incluso un tool gratuito per creare frame.md dal tuo design.md.
- HyperFrames è il motore video open source di HeyGen: scrivi HTML e il sistema renderizza MP4, con supporto GSAP, Lottie e Three.js e nessun formato proprietario.
