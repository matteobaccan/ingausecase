# Butterbase

## Introduzione

Backend open source con IA nativa integrata: Postgres RLS, auth, storage, AI Gateway e server MCP.

## Funzionalità principali

- Butterbase ha aperto tutto il codice: Postgres con RLS, autenticazione, OAuth, storage, functions, AI Gateway e server MCP; il backend si trasforma in tool reali per Claude, Cursor e qualsiasi agente; self-host gratis o managed.
