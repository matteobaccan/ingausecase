# n8n

## Introduzione

Piattaforma open source self-hosted per l'automazione di workflow, segnalata per workflow AI.

## Funzionalità principali

- n8n è stato indicato come alternativa open source gratuita a Zapier per l'automazione dei workflow.
- n8n è stato segnalato tra i repository GitHub per l'automazione di workflow con AI, per l'automazione self-hosted.
