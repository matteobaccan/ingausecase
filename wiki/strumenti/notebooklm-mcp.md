# NotebookLM MCP

## Introduzione

Server MCP sviluppato dalla community che collega [[claude-code]] a Google NotebookLM, permettendo all'agente di leggere documentazioni complete senza consumare token del piano Anthropic. [Fonte: raw/pillitteri/pillitteri20260430-collegare-claude-code-notebooklm-mcp-token-gratis-2026.md]
