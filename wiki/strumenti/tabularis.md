# Tabularis

## Introduzione

Workspace SQL open source con server MCP integrato per PostgreSQL, MySQL, SQLite, DuckDB, ClickHouse, Redis e Firestore, pensato per l'uso da parte di agenti.

## Funzionalità principali

- Workspace SQL open source con server MCP integrato: si collegava a PostgreSQL, MySQL, SQLite, DuckDB, ClickHouse, Redis e Firestore. Gli agenti potevano vedere connessioni, leggere schemi, scrivere ed eseguire query dal chat.
