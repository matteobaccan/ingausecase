# Merge Gateway

## Introduzione

Gateway (proxy) per modelli LLM tramite cui accedere a modelli come GLM 5.3 Flash.

## Funzionalità principali

- GLM 5.3 Flash risulta disponibile su Merge Gateway, con novanta percento di sconto fino a fine settembre e nessuna chiave API richiesta per l'uso.

## Timeline delle notizie

- **2026-08-28** — GLM 5.3 Flash è disponibile anche su Merge Gateway, con novanta percento di sconto fino a fine settembre. [Fonte: raw/puntate/ainews20260828.md]
