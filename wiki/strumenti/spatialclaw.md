# SpatialClaw

## Introduzione

Agente training-free di NVIDIA Research che usa codice Python come interfaccia action per task visivi complessi.

## Funzionalità principali

- SpatialClaw di NVIDIA Research è un agente training-free che usa codice come interfaccia action per task visivi complessi: scrive Python in kernel persistente, compone moduli perception, ispeziona risultati intermedi e rivede la strategia cross-step, battendo il prior recente di undici punto due punti su venti benchmark senza tuning specifico.
