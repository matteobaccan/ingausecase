# Tauri

## Introduzione

Framework per app desktop leggere basato su Rust, alla base di Pake.

## Funzionalità principali

- Tauri è il framework di Pake: il tool in Rust converte pagine web in app da circa cinque megabyte, venti volte più leggere di Electron.
