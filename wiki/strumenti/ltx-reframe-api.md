# LTX Reframe API

## Introduzione

API di LTX che espande video a nuovi formati senza ritagliare o allucinare, generando solo i bordi attorno al frame originale.

## Funzionalità principali

- LTX Reframe API espande video a nuovi formati senza ritagliare o allucinare: il frame originale resta intatto e il modello genera solo i bordi, fino a sessanta secondi a 1080p nativo.
