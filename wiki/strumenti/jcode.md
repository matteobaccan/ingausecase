# jcode

## Introduzione

Harness per agent di coding scritto in Rust e open source, che si avvia 245 volte più velocemente di Claude Code con consumo di RAM drasticamente ridotto.

## Funzionalità principali

- Harness per agent di coding che si avviava 245 volte più velocemente di Claude Code: primo frame in 14 millisecondi contro 3.436, e 27,8 MB di RAM contro 386,6 MB.
- Scritto in Rust e open source: 245 volte più veloce di Claude Code, prima uscita in 14 ms contro 3,4 secondi, 27,8 MB di RAM contro 386 MB.
- Harness per coding agent scritto in Rust con grafo di memoria semantico, oltre trenta provider, modalità swarm e self-dev.
