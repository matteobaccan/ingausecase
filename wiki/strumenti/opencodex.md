# OpenCodex

## Introduzione

Gateway locale per sbloccare API di terze parti dentro Codex Desktop, con web panel e Computer Use a latenza bassissima anche su modelli non multimodali.

## Funzionalità principali

- OpenCodex è un gateway locale per sbloccare API di terze parti dentro Codex Desktop: zero configurazione, web panel per inserire chiave e nome modello; Computer Use con screenshot compressi e descrizione visiva a latenza bassissima, funzionante anche su modelli non multimodali.
- opencodex integrava Grok, Kimi, Claude, Gemini, DeepSeek, GLM, Qwen e Ollama locale dentro Codex: cambiavi modello come cambi canale, con tre comandi per installarlo.
