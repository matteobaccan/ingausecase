# Hermes Agent Desktop

## Introduzione

Versione desktop di Hermes Agent con browser integrato: l'agente vede e opera su cio' che vedi, guarda video YouTube, estrae trascrizioni e genera post.

## Funzionalità principali

- Hermes Desktop dà un'interfaccia decente a Hermes Agent: installazione automatica senza terminale, chat in streaming con tracciamento token, profili multipli, memoria visibile e modificabile, quattordici categorie di strumenti, scheduler e sedici gateway di messaggistica (Telegram, WhatsApp, Discord, Slack, Signal).
- Hermes Desktop è entrato in public preview: agente AI nativo per Mac, Windows e Linux che connette ChatGPT, GPT-5.5, Codex e Claude Code Skills in un'unica interfaccia, MIT e gratis; Jensen Huang lo ha mostrato in demo al GTC.
- Hermes Desktop Agent ha imparato TouchDesigner da zero: ha navigato il desktop, letto riferimenti visivi, iterato sulla grafica con l'utente e salvato quanto appreso come skill riutilizzabile; tutto basato su MiniMax M3.
