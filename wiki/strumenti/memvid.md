# memvid

## Introduzione

Memoria portabile per agenti IA con circa sedicimila stelle: livello memoria single-file, append-only, che semplifica il RAG senza vector DB complessi.

## Funzionalità principali

- memvid e' una memoria portabile per agenti IA con circa sedicimila stelle: livello memoria single-file con ricerca veloce senza RAG o vector DB complessi, memoria portabile append-only che semplifica il RAG pesante.
