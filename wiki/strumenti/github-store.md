# GitHub Store

## Introduzione

Trasforma i rilasci GitHub in un app store pulito, sviluppato da un diciassettenne uzbeko.

## Funzionalità principali

- GitHub Store rimuove la confusione del download dai rilasci GitHub: rileva file installabili, mostra la versione corretta per il dispositivo e installa e aggiorna direttamente su Android, Windows, macOS e Linux; open source.
