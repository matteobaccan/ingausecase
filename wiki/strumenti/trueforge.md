# TrueForge

## Introduzione

Harness open source che implementa pratiche di ottimizzazione per gli agenti di coding.

## Funzionalità principali

- TrueForge è un harness open source che implementa pratiche di ottimizzazione: schemi di tool differiti, risposte grandi su file in sandbox e codice generato che chiama i tool attraverso il harness. Ha risolto lo stesso numero di task di Claude Managed Agents usando un terzo dei token.
