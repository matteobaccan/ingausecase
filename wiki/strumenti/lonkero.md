# Lonkero

## Introduzione

Scanner di sicurezza web modulare in Rust per penetration test, con oltre centoventicinque capacita' di scansione e machine learning per ridurre i falsi positivi.

## Funzionalità principali

- Lonkero e' uno scanner di sicurezza web modulare in Rust per penetration test: oltre centoventicinque capacita' di scansione avanzate, machine learning per ridurre i falsi positivi e scanner XSS proof-based senza dipendenze browser.
