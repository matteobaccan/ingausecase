# ant CLI

## Introduzione

CLI ufficiale di Anthropic per Claude Platform, esegue ogni endpoint API dal terminale.

## Funzionalità principali

- ant CLI è la CLI ufficiale di Anthropic per Claude Platform: chiama la Messages API, lancia Claude Managed Agents e pipe i risultati nella shell; riconosciuto da Claude Code tramite la skill claude-api.
