# TablePro

## Introduzione

Strumento che si connette a database SQL e NoSQL e integra una chat IA, con supporto MCP per Cursor e Raycast.

## Funzionalità principali

- Connessione a database SQL e NoSQL.
- Avvio in meno di un secondo, ottanta megabyte di RAM inattiva.
- Chat IA integrata con supporto MCP per Cursor e Raycast.
