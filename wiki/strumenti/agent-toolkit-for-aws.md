# Agent Toolkit for AWS

## Introduzione

Suite ufficiale di [[aws]], annunciata il 6 maggio 2026, che dà agli agenti AI di programmazione strumenti, conoscenza e guardrail per lavorare sui servizi cloud AWS senza inventare comandi inesistenti.

## Funzionalità principali

- **AWS MCP Server**: server gestito basato su [[mcp]], in disponibilità generale, che copre oltre 300 servizi AWS e più di 15.000 azioni API, esegue script Python in ambiente isolato e dà accesso alla documentazione aggiornata, con controllo via IAM.
- **Agent Skills**: oltre 40 procedure validate al lancio, distribuite su sei aree (infrastruttura come codice, storage, analytics, serverless, container, servizi AI).
- **Agent Plugins**: tre pacchetti al debutto (AWS Core, AWS Data Analytics, AWS Agents), installabili con un clic su Claude Code, Cursor e Codex.
- Nessun costo aggiuntivo: si paga solo per le risorse AWS create, in due region (Virginia del Nord e Francoforte).
