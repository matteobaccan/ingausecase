# MarkItDown

## Introduzione

Strumento di Microsoft (100mila stelle) che trasforma qualsiasi file (PDF, Word, PowerPoint, Excel, immagini) in Markdown pulito; gratuito, open source e con uso commerciale permesso.

## Funzionalità principali

- MarkItDown di Microsoft ha 100000 stelle: trasforma qualsiasi file in Markdown pulito (PDF, Word, PowerPoint, Excel, immagini), gratuito, open source e con uso commerciale permesso; testato su un PDF da 200 pagine ha prodotto Markdown perfetto in pochi secondi, risolvendo l'inferno dei documenti reali per i sistemi RAG.
- MarkItDown di Microsoft converte PDF, Word, PPT, Excel, immagini, audio e HTML in Markdown pulito: centosessanta lingue supportate, ideale per preprocessing RAG e knowledge base.
- MarkItDown di Microsoft ha raggiunto centomila stelle su GitHub: tool Python open source che converte PDF, Word, PowerPoint, Excel e immagini in Markdown, con uso commerciale libero.
