# img2threejs

## Introduzione

Strumento che converte foto in scene Three punto js funzionanti: input immagine, output modello 3D eseguibile.

## Funzionalità principali

- img2threejs trasforma una foto di oggetto in un modello Three.js procedurale senza mesh scaricato, con loop render-vs-reference per quality gating, ottimo per oggetti hard-surface.
- img2threejs converte foto in scene Three punto js funzionanti: input un'immagine, output un modello tre D eseguibile.
