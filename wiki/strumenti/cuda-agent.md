# CUDA Agent

## Introduzione

Sistema agentico di ByteDance che scrive kernel CUDA tramite apprendimento per rinforzo, meglio degli esperti umani. Supera modelli proprietari occidentali del 40% sui benchmark più difficili e va dal 92% al 100% più veloce di torch.compile.

## Funzionalità principali

- CUDA Agent di ByteDance scrive kernel CUDA meglio degli esperti umani: fino a tre punto due volte più veloce dell'esecuzione nativa di PyTorch e batte Claude Opus 4.5 e Gemini 3 Pro del quaranta percento sui modelli più complessi.
