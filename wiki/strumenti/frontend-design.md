# frontend-design

## Introduzione

Skill ufficiale di Anthropic per Claude che forza il modello a scegliere una direzione estetica (brutalista, editoriale, retro-futurista, lujoso, maximalista) prima di scrivere codice. Genera HTML, CSS, JS, React o Vue production-ready.
