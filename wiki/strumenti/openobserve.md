# OpenObserve

## Introduzione

Piattaforma di osservabilita' in Rust che sostituisce tool di logging costosi: AGPL tre virgola zero, storage centoquaranta volte piu' economico con architettura Parquet piu' S3.

## Funzionalità principali

- OpenObserve e' una piattaforma di osservabilita' in Rust che sostituisce tool di logging costosi: licenza AGPL tre virgola zero, deploy a singolo file, storage che costa centoquaranta volte meno grazie a Parquet piu' S3; log, metriche, tracciamento, RUM frontend e monitoring LLM in un pacchetto unico, con query SQL o PromQL dirette.
