# Skill Recorder

## Introduzione

Sistema Microsoft che registra lo schermo durante un task e converte tutto in documentazione e automazione, trasformando le azioni in API e comandi stabili.

## Funzionalità principali

- Microsoft ha rilasciato Skill Recorder: registravi lo schermo mentre fai un task e il sistema convertiva tutto in documentazione e automazione, trasformando le azioni in API e comandi stabili. Compatibile con Microsoft Scout e Microsoft 365 Copilot Cowork.
