# Ollama-OCR

## Introduzione

Strumento OCR locale che estrae testo da immagini e PDF senza API esterne, con output Markdown o JSON: i documenti non escono mai dal dispositivo.

## Funzionalità principali

- OCR offline completo, nessun costo API: supporta LLaVA, Llama 3.2 Vision, Granite 3.2-vision, Moondream, MiniCPM-V. Sei formati di output (Markdown, testo, JSON, dati strutturati, coppie chiave-valore, tabelle) e app Streamlit inclusa.
- Estrae testo da immagini e PDF senza API esterne, tutto in locale: legge fatture, ricevute, tabelle e scrittura a mano, output in Markdown o JSON. I documenti sensibili non escono mai dal dispositivo.
