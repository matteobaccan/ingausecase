# Figures4papers

## Introduzione

Repository dell'università di Yale pubblicato su GitHub che raccoglie script per generare grafici da paper scientifici.

## Funzionalità principali

- Otto progetti che coprono grafici a barre, radar, linee e sfere tridimensionali.
- Include una skill per Cursor, Claude Code o Codex, così gli agenti scrivono script seguendo le convenzioni del ricercatore.
