# TeamAI-CLI

## Introduzione

Strumento di [[tencent]] che trasforma conoscenza di team in un repository git unico, così ogni agent lavora dallo stesso manuale. Funziona con Claude Code, Codex, Cursor, OpenCode, CodeBuddy e WorkBuddy. Le modifiche passano per merge request, skill e regole acquisiscono confidenza da uso reale. [Fonte: raw/puntate/ainews20260908.md]

## Funzionalità principali

- Trasforma conoscenza di team in repository git unico per allineare tutti gli agent sullo stesso manuale. [Fonte: raw/puntate/ainews20260908.md]
- Compatibile con Claude Code, Codex, Cursor, OpenCode, CodeBuddy e WorkBuddy. [Fonte: raw/puntate/ainews20260908.md]
- Flusso via merge request; skill e regole acquisiscono confidenza da uso reale. [Fonte: raw/puntate/ainews20260908.md]
