# CrewAI

## Introduzione

Framework Python open source per costruire crew di agenti IA multi-agente, usato dal sessanta percento delle Fortune 500.

## Funzionalità principali

- Nel corso gratuito di Microsoft su agenti AI, CrewAI permette di costruire il primo crew multi-agente in meno di tre ore; è usato dal 60% delle Fortune 500.
- CrewAI è stato citato come framework compatibile con Agent Governance Toolkit di Microsoft per la governance delle tool call.
- CrewAI è citato tra i framework con cui funziona Memanto, lo strumento che dà memoria infinita agli agenti IA.
