# Nx Console

## Introduzione

Estensione VS Code (2,2 milioni di installazioni) compromessa, usata per infettare GitHub tramite un dipendente.

## Funzionalità principali

- Nx Console, estensione VS Code con 2,2 milioni di installazioni, è stata la via d'accesso della compromissione di GitHub: un dipendente l'ha installata, l'estensione è rimasta 11 minuti online e ha rubato token da GitHub, npm, AWS, Kubernetes e 1Password, esponendo 3800 repository interni.
