# VS Code

## Introduzione

Editor di codice di Microsoft, ora in grado di connettersi direttamente a Google Colab per eseguire su GPU gratuite.

## Funzionalità principali

- VS Code ora si connette direttamente a Google Colab: scrivi in locale, esegui su GPU gratuita T4 o superiore, zero configurazione server.

## Timeline delle notizie

- **2026-07-06** — VS Code ora si connette direttamente a Google Colab: scrivi in locale, esegui su GPU gratuita T4 o superiore, zero configurazione server.
- **2026-10-29** — Nella ricerca EMBRACE il browser integrato dell'editor lascia che una pagina locale limiti la lettura alla cartella del progetto solo per la pagina stessa, mentre un web worker avviato da quella pagina legge qualunque file del computer; Microsoft ha respinto la segnalazione del 10 settembre 2026 come non valida, sostenendo che la lettura avviene solo dopo la conferma del Workspace Trust.
