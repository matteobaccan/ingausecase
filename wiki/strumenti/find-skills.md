# Find Skills

## Introduzione

Pacchetto MCP creato da un developer giapponese che scansiona centinaia di skill nell'ecosistema Anthropic e costruisce workflow automatici da un solo prompt.

## Funzionalità principali

- Find Skills è un pacchetto MCP per Claude Code che scansiona centinaia di skill nell'ecosistema Anthropic e costruisce un workflow automatico ottimale da un singolo prompt: script video su Notion più Claude, B-roll con Veo3, thumbnail con Sora, caption e timing con Buffer, analytics con Typefully, per un canale YouTube che produce contenuto continuo con un solo operatore.
