# CLAUDE.md di Karpathy

## Introduzione

File di istruzioni di Andrej Karpathy con 65 righe e 4 regole che ha portato l'accuratezza dell'AI coding dal 65% al 94%; 220mila stelle su GitHub Trending.

## Funzionalità principali

- È uscita la CLAUDE.md di Karpathy: 65 righe, 4 regole (pensa prima di scrivere, codice minimo, solo modifiche chirurgiche, criteri verificabili prima di iniziare), ha portato l'accuratezza dell'AI coding dal 65% al 94%, con 220000 stelle e numero uno su GitHub trending.
- Karpathy ha pubblicato la CLAUDE.md: 65 righe, accuratezza coding dal 65% al 94%, 220000 stelle su GitHub Trending, con quattro regole (pensa prima di scrivere, parti dal minimo, modifica con precisione chirurgica, traduci ogni richiesta in standard verificabile).
- CLAUDE.md è il documento con quattro regole per ottimizzare il comportamento di Claude in programmazione, rilasciato da Andrej Karpathy: quarantaquattro K stelle in una settimana; ragionare prima di scrivere, codice conciso, modifiche mirate e obiettivo funzionale.
