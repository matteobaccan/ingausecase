# Cline Desktop

## Introduzione

Interfaccia nativa di Cline per lavorare con modelli open weights, alternativa desktop all'agente di coding in VS Code della stessa azienda. [Fonte: raw/puntate/ainews20260915.md]

## Funzionalità principali

- Si usa con [[clinepass]] e tutti i modelli gratuiti del catalogo Cline, tra cui [[deepseek-v4-1-flash]] e [[muse-spark-1-3]]. [Fonte: raw/puntate/ainews20260915.md]
- In alternativa al catalogo Cline si possono portare le proprie chiavi API con qualsiasi provider. [Fonte: raw/puntate/ainews20260915.md]
