# WebToApp

## Introduzione

Strumento che converte progetti web in APK Android direttamente da smartphone, con runtime locali e build on-device.

## Funzionalità principali

- WebToApp converte progetti web in APK Android direttamente da smartphone: server runtime locale per Node, PHP, Python, Go e WordPress, build e signing on-device, nessun server esterno.
