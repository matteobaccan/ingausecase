# ClinePass

## Introduzione

Abbonamento flat di Cline che dà accesso a un catalogo curato di modelli open-weight attraverso provider, senza chiavi API separate.

## Funzionalità principali

- Abbonamento mensile flat che apre l'accesso a modelli open-weight curati: GLM 5.2, Kimi K2.7 Code, DeepSeek V4 Pro, MiniMax-M3 e Qwen 3.7, sostituendo chiavi API separate attraverso provider.
