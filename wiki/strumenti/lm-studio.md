# LM Studio

## Introduzione

Applicazione desktop gratuita per macOS, Windows e Linux che scarica modelli linguistici aperti e li esegue in locale, con un'interfaccia simile a ChatGPT e un server compatibile con le API di OpenAI.

## Funzionalità principali

- Sotto il cofano lavora con due motori, llama.cpp e MLX, e con i formati GGUF e MLX.
- Gratuita anche in azienda dall'8 luglio 2025; l'app desktop è a codice chiuso, mentre la riga di comando `lms`, gli SDK per Python e TypeScript e il motore MLX sono pubblici su GitHub.
- Sul Mac richiede un processore Apple Silicon con macOS 14 o successivo; versione citata 0.4.25 del 19 settembre 2026.

## Casi d'uso

- Interrogare contratti, preventivi, bilanci e relazioni interne senza che i documenti lascino la macchina.
