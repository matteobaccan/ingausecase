# Edge0

## Introduzione

Framework open source per eseguire modelli IA grandi su iPhone, senza cloud, server remoto o GPU desktop.

## Funzionalità principali

- Esegue un modello da trentacinque miliardi di parametri usando solo da uno a due punto cinque gigabyte di memoria su iPhone.
- Nessun cloud, nessun server remoto, nessuna GPU desktop: solo il telefono.
