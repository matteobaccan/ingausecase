# Edge0

## Introduzione

Framework open source per eseguire modelli IA grandi su iPhone, senza cloud, server remoto o GPU desktop. [Fonte: raw/puntate/ainews20260911.md]

## Funzionalità principali

- Esegue un modello da trentacinque miliardi di parametri usando solo da uno a due punto cinque gigabyte di memoria su iPhone. [Fonte: raw/puntate/ainews20260911.md]
- Nessun cloud, nessun server remoto, nessuna GPU desktop: solo il telefono. [Fonte: raw/puntate/ainews20260911.md]
