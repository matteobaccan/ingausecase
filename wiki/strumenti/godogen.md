# Godogen

## Introduzione

Progetto GitHub che costruisce giochi Godot completi da prompt in linguaggio naturale, autocorrettivo.

## Funzionalità principali

- Godogen su GitHub: prompt in, gioco Godot out; l'AI costruisce progetto, logica, asset ed engine e se l'output non funziona il sistema si corregge da solo, tutto automatico dall'idea al primo prototipo giocabile.
