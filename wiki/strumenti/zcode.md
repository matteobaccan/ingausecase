# ZCode

## Introduzione

IDE desktop di Zhipu AI per coding con GLM 5.2 integrato: tre milioni di token gratuiti al giorno, Goal Mode per pianificare ed eseguire task, subagenti e controllo remoto del telefono.

## Funzionalità principali

- Ambiente di sviluppo ufficiale di GLM 5.2: gli abbonati GLM Coding Plan ricevono quota d'uso aumentata del 50%, supporta Bring Your Own Key, disponibile su macOS, Windows e Linux.
- ZCode e' un IDE desktop per coding con GLM cinque punto due integrato: tre milioni di token gratuiti al giorno senza carta di credito (quota resettata ogni giorno), Goal Mode per pianificare ed eseguire task, subagenti, controllo remoto del telefono e chatbot integrati, con possibilita' di portare le proprie API key.

La scoperta è di uno sviluppatore che si firma Ferstar, il 18 settembre 2026: la cartella `~/.zcode` occupava oltre 700 MB e in `~/.zcode/v2/checkpoints/` c'erano archivi cifrati, uno da 313 MB con un manifesto di 42.411 file e l'86,6 per cento del volume in dati Git; fino alla versione 3.12.3 nessun interruttore fermava la funzione e la privacy policy non ne parlava.
- **2026-10-01** — Un'analisi dell'assistente di coding ZCode, sviluppato da Zhipu/Z.ai, rileva il caricamento nel cloud di workspace completi, comprese directory .git con cronologie, file eliminati e potenziali credenziali: in un caso l'archivio trasferito conteneva oltre 42.000 file. Z.ai ha attribuito il comportamento a una funzione di indicizzazione attiva per impostazione predefinita, si è scusata e ha annunciato rimedi.
- **2026-10-13** — GLM-5.3-Highspeed di Zhipu compare in un rilascio grigio di ZCode riservato a iscritti scelti a caso, con utenti che misurano circa 490 token al secondo.
