# Unified Harness Protocol

## Introduzione

Unified Harness Protocol è un layer infrastrutturale che permette di eseguire [[codex]], [[hermes-agent]], [[claude-code]], [[deepseek-harness]], System One powered by [[jev]] e altri nove harness sotto un'unica interfaccia.

## Funzionalità principali

- Esecuzione unificata di oltre 14 harness diversi con singola interfaccia.
- Compatibile API OpenAI Responses.
- Gli harness girano in locale.

## Timeline delle notizie

- **2026-09-22** — Presentato Unified Harness Protocol, layer che unifica Codex, Hermes, Claude Code, DeepSeek Harness, System One e altri nove harness con API compatible OpenAI Responses in locale.
- **2026-10-17** — HarnessRouter, implementazione open source del protocollo UHP, standardizza l'interfaccia per eseguire task agent su qualsiasi harness rendendo l'infrastruttura completamente intercambiabile: nel primo benchmark controllato riduce i costi fino a 2,1 volte usando circa il 53% di crediti in meno.
