# OpenUI

## Introduzione

Spec open source (MIT) che genera componenti UI con il 67% di token in meno rispetto a JSON, model-agnostic e framework-neutral (React, Vue, Svelte, HTML).

## Funzionalità principali

- OpenUI è una spec open source che genera componenti UI con il 67% di token in meno rispetto a JSON: streamabile by design, component-first, compila a React, Vue, Svelte o HTML puro, primitive integrate per form, grafici, tabelle, modal e dashboard, schema type-safe, zero dipendenza runtime, MIT; funziona con Claude, GPT, Gemini, DeepSeek e Llama, riducendo le bollette di due terzi su ogni chiamata di generazione UI.
