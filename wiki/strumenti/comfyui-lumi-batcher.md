# ComfyUI Lumi Batcher

## Introduzione

Tool di ByteDance che automatizza il batch processing per ComfyUI con combinazioni di parametri illimitate.

- ComfyUI Lumi Batcher di ByteDance automatizza il batch processing per ComfyUI: combinazioni parametri illimitate, risultati in tabelle multidimensionali, gestione smart dei file e supporto multimodale.
