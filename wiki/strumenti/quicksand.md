# Quicksand

## Introduzione

API Python asincrona di [[microsoft]] per avviare, controllare e salvare snapshot di macchine virtuali QEMU, con particolare attenzione al sandboxing degli agenti AI.

## Funzionalità principali

- Fornisce VM Linux pre-costruite per Ubuntu e Alpine, supporta x86_64 e ARM64 su macOS, Linux e Windows e non richiede privilegi di root né Docker.
