# Mobile MCP

## Introduzione

Mobile MCP connette iOS e Android a Claude Code, Codex, Gemini e GitHub Copilot tramite Model Context Protocol. [Fonte: raw/puntate/ainews20260909.md]

## Funzionalità principali

- Gestione dispositivi, installazione app, tap su schermo, input e log. [Fonte: raw/puntate/ainews20260909.md]
- Connessione di dispositivi mobili ad agenti di coding tramite MCP. [Fonte: raw/puntate/ainews20260909.md]
