# OfficeCLI

## Introduzione

Suite Office a linea di comando progettata per agenti IA, che permette di leggere, modificare e creare file Word, Excel e PowerPoint, con binario singolo senza dipendenze e output JSON.

## Funzionalità principali

- OfficeCLI è la prima suite Office progettata per agenti IA: permette di leggere, modificare e creare file Word, Excel e PowerPoint da linea di comando, con binario singolo senza dipendenze e output JSON strutturato, su macOS, Linux e Windows.
- OfficeCLI crea, legge e modifica file Word, Excel e PowerPoint dal terminale senza installare Office; Claude Code e Cursor possono controllare i file Office tramite script; open source e leggero.
