# UnlimCloud

## Introduzione

App desktop gratuita per storage cloud illimitato via Telegram, interfaccia Rust/Tauri, MIT.

## Funzionalità principali

- UnlimCloud è un'app desktop gratuita con storage cloud illimitato via Telegram: ogni file fino a due giga salvato nei messaggi personali, interfaccia in Rust via Tauri; Windows disponibile, macOS e Linux in arrivo; licenza MIT.
