# skills.sh

## Introduzione

Package manager per skill agente di Vercel Labs, con novecentotrentamila skill disponibili e gestione simile a npm.

- skills.sh di Vercel Labs è un package manager per skill agente: novecentotrentamila skill disponibili, un comando le installa per Claude Code, Cursor, Codex, Copilot e più di sessanta agenti, con gestione come npm.
