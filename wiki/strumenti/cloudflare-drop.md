# Cloudflare Drop

## Introduzione

Servizio di Cloudflare per il deploy immediato di cartelle locali su edge network globale, senza registrazione, server o dominio.

## Funzionalità principali

- Cloudflare Drop permette di trascinare una cartella locale nel browser per un deploy immediato su edge network globale: nessuna registrazione, nessun server, nessun dominio, sessanta minuti di hosting gratis.
