# AnyDoc

## Introduzione

Parser locale open source basato su Rust per PDF, DOCX, PPTX e altri dieci formati, con conversione in markdown sotto i cinque millisecondi. Integrato in Firecrawl.

## Funzionalità principali

- AnyDoc e' un parser locale per PDF, DOCX, PPTX e altri dieci formati con conversione in markdown sotto i cinque millisecondi: cinquecento file docx in uno punto sette secondi, basato su Rust, open source e gia' dentro Firecrawl.
