# MiMo Code V0.1

## Introduzione

Assistant da terminale open source con MiMo V2.5 multimodale, contesto da un milione di token, licenza MIT.

## Funzionalità principali

- MiMo Code V0.1 arriva open source: assistant da terminale con MiMo V2.5 multimodale gratis per tempo limitato, contesto da un milione di token, compressione senza perdite anche su progetti milionari; modalità Compose per specifiche, piani, build e report; input vocale con MiMo-V2.5-ASR; compatibile con skill e server MCP di Claude Code; MIT.
- MiMo Code di Xiaomi è un tool gratuito per coding con AI: modello MiMo Auto senza API key, memoria persistente e sub-agenti paralleli, su Mac, Linux e Windows.
