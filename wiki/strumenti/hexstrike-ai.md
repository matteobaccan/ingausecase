# HexStrike AI

## Introduzione

Sistema che trasforma [[claude]] in pentester autonomo. Collega un LLM a oltre 150 strumenti professionali di cybersecurity tramite MCP. Include 12 agent specializzati, test su network e web security, workflow automatizzati, esecuzione locale su Kali Linux. Claude ha generato autonomamente payload SQL injection, eseguito test e risolto un lab PortSwigger.

## Funzionalità principali

- Collega LLM a oltre 150 strumenti professionali di cybersecurity tramite MCP.
- 12 agent specializzati, test su network e web security, workflow automatizzati.
- Esecuzione locale su Kali Linux.
- Capacità dimostrate: generazione autonoma di payload SQL injection, esecuzione test e risoluzione di lab PortSwigger.
