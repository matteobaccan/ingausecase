# lightweight-charts

## Introduzione

Libreria open source di grafici trading del team ufficiale TradingView, alternativa gratuita a TradingView Pro.

## Funzionalità principali

- lightweight-charts, 14.000 stelle e creato dal team ufficiale TradingView, sostituisce TradingView Pro in una lista di sei repository GitHub che eliminano abbonamenti per quasi 3.000 dollari al mese.
