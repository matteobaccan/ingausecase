# Multica

## Introduzione

Sistema self-host per eseguire coding agent come teammate reali: assegna issue a Claude Code, Codex, Cursor o altri diciassette, con commenti mentre lavorano e PR finali. Quarantacinquemila stelle.

## Funzionalità principali

- Multica rilascia un sistema per eseguire coding agent come teammate reali: assegna issue a Claude Code, Codex, Cursor o altri diciassette; ogni agente commenta mentre lavora e restituisce PR, con standup, audit e report su cron; self-host totale, quarantacinquemila stelle.
