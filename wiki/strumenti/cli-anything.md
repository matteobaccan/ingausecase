# CLI-Anything

## Introduzione

Progetto da Hong Kong che trasforma qualsiasi software GUI o API in uno strumento a riga di comando usabile dagli agenti AI.

## Funzionalità principali

- Trasformava qualsiasi software GUI o API in uno strumento a riga di comando per agenti (Blender, GIMP, FreeCAD, Kdenlive). Funzionava con Claude Code, Codex e Gemini, con 2.280 test passati e documentazione automatica.
