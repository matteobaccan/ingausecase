# VoiceBox

## Introduzione

Repository GitHub di jamiepine che clona la voce con pochi secondi di audio, girando in locale sul proprio PC; Claude Code, Cursor e agenti MCP rispondono con quella voce.

## Funzionalità principali

- VoiceBox replica ElevenLabs e WisprFlow insieme, completamente locale: clonaggio vocale, input vocale globale, voce per AI agents, con 7 motori TTS integrati e 23 lingue; nessuna API key, nessun limite, dati offline e open source.
- Voicebox ha ventinove punto due mila stelle su GitHub: clone vocale da dieci secondi, ventitré lingue, sette motori TTS intercambiabili ed editor multi-traccia per podcast e dialoghi; totalmente locale, nessun abbonamento.
- Alternativa locale e open source a ElevenLabs e WisprFlow: text-to-speech completamente in locale, senza dipendenze cloud. Tra i cinque repository esplosi questa settimana.
