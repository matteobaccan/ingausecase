# Unreal MCP

## Introduzione

Unreal Model Context Protocol, il modo ufficiale supportato da Epic per collegare tool LLM agentici direttamente a [[unreal-engine-5-8|Unreal Engine]]. [Fonte: raw/puntate/ainews20261009.md]

## Funzionalità principali

- Costruito sullo standard aperto [[mcp]], permette agli agenti di agire nei progetti usando le capacità esposte dall'editor. [Fonte: raw/puntate/ainews20261009.md]

## Timeline delle notizie

- **2026-10-09** — Unreal Engine rilascia Unreal Model Context Protocol, connessione ufficiale supportata da Epic tra tool LLM agentici e Unreal Engine basata sullo standard aperto [[mcp]]: gli agenti agiscono nei progetti tramite le capacità esposte dall'editor. [Fonte: raw/puntate/ainews20261009.md] Il 21 ottobre il plugin arriva su GitHub con il controllo diretto dell'editor da [[claude-code|Claude Code]]: crea actor, connette nodi blueprint, gestisce materiali e animazioni, con oltre trenta toolset, centinaia di strumenti sottostanti e un sistema di ricerca on-demand per non saturare il contesto. [Fonte: raw/puntate/ainews20261021.md]
