# Open Knowledge Format

## Introduzione

Specifica aperta di Google che formalizza il pattern LLM-wiki in formato portabile e interoperabile a base di Markdown e YAML frontmatter.

## Funzionalità principali

- Open Knowledge Format di Google è uno standard aperto per memorizzare informazioni in directory di file markdown: i file si collegano tra loro e servono come wiki vivente che gli agenti possono interrogare o modificare.
- Google ha annunciato Open Knowledge Format, specifica aperta che formalizza il pattern LLM-wiki in formato portabile e interoperabile: solo markdown leggibile in qualsiasi editor, file shippabili come tarball e YAML frontmatter per campi strutturati queryabili; Knowledge Catalog lo ingerisce nativamente.
