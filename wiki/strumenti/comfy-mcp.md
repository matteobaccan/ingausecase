# Comfy MCP

## Introduzione

Server MCP di Comfy in beta pubblica: esegue qualsiasi workflow ComfyUI in linguaggio naturale, con ricerca di modelli, nodi e template.

## Funzionalità principali

- Beta pubblica del primo MCP per pipeline produttive: connette Claude, Codex, Cursor e Hermes all'ecosistema ComfyUI, esegue workflow in linguaggio naturale, cerca modelli, nodi e template. Centinaia di workflow pre-costruiti sempre aggiornati.
