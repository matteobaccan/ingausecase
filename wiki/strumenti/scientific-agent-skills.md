# Scientific Agent Skills

## Introduzione

Collezione open source di skill per agenti di ricerca in biologia, chimica e medicina, ospitata nel repository google-deepmind/science-skills e citata per la prima volta tra i repository interessanti della settimana dell'8 settembre 2026.

## Funzionalità principali

- Ogni skill è un pacchetto di istruzioni, script e documentazione che l'agente carica solo quando serve.
- Il repository è nato il 13 maggio 2026 e il 18 ottobre 2026 contava 3.287 stelle e 372 fork; il software è sotto licenza Apache 2.0 e gli altri materiali sotto CC-BY 4.0, con il README che precisa non essere un prodotto ufficiale Google.
- Copre oltre trenta database e strumenti per le scienze della vita, tra cui AlphaGenome Atlas, UniProt, PubChem e ChEMBL.
- Si installa dal marketplace di Antigravity con un clic (Customizations, Build with Google, Science, Add) oppure da terminale con npx skills add google-deepmind/science-skills/.
- Alcune skill richiedono una chiave API, per esempio AlphaGenome e OpenAlex; per altre come ClinVar la chiave è facoltativa e alza i limiti di richieste.
