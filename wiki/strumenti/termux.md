# Termux

## Introduzione

Ambiente shell per Android che permette di eseguire tool Linux su dispositivi mobili. Nella puntata è segnalato per script che convertono vecchi telefoni Android in desktop Linux con accelerazione GPU o server Home Assistant senza bisogno di root.

## Funzionalità principali

- Script shell che trasformano vecchi telefoni Android in desktop Linux con accelerazione GPU.
- Utilizzo come server Home Assistant senza accesso root.
- Esecuzione di ambiente Linux su Android tramite Termux.
