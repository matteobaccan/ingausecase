# Open-Generative-AI

## Introduzione

Piattaforma open source (licenza MIT) che integra oltre duecento modelli generativi per immagini e video.

## Funzionalità principali

- Piattaforma open source che integra oltre duecento modelli generativi per immagini, video, sincronizzazione labiale e controllo cinematografico: nessun filtro di contenuti, output locale a 1080p, modalità locale più cloud, app desktop per macOS, Windows e Linux, licenza MIT.
