# ReClip

## Introduzione

Repo GitHub open source e self-hosted che scarica video da oltre mille siti web (YouTube, TikTok, Instagram, Twitter/X) come MP4 o MP3, senza pubblicità, popup o tracker.

## Funzionalità principali

- ReClip, repo open source self-hosted per scaricare video da quasi ogni sito (YouTube, TikTok, Instagram, Twitter/X e più di mille altri), supporta output MP4 o MP3, selezione risoluzione e download batch, ed è passato da zero a 1.400 stelle GitHub in nove giorni.
