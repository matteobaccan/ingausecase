# OpenDataLoader PDF

## Introduzione

Parser PDF open source per pipeline RAG, 116 volte più veloce di Marker su benchmark.

## Funzionalità principali

- Parser PDF per pipeline RAG centosedici volte più veloce di Marker con punteggio benchmark 0.907: gestisce tabelle, formule, immagini, grafici e OCR per oltre ottanta lingue, output in Markdown, JSON o HTML, integrazione nativa con LangChain, 0.46 secondi per pagina su CPU locale, licenza Apache 2.0 e ventiquattromila stelle su GitHub.
