# Verifiers

## Introduzione

Framework open source di Prime Intellect per creare ambienti di addestramento RL, con hub centrale di ambienti già pronti.

## Funzionalità principali

- Verifiers di Prime Intellect è un framework open source MIT per costruire ambienti di addestramento RL: hub centrale con oltre duemilacinquecento ambienti, include dataset, harness e rubrica di scoring.
