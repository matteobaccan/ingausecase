# Prime Agent

## Introduzione

Harness auto-migliorante open source di Prime Intellect che trasforma modelli frontier in Recursive Language Models; con Opus 5 raggiunge il novantacinque virgola cinque percento su ARC-AGI-3. MIT.

## Funzionalità principali

- Prime Agent e' un harness RLM self-improving: tool calling programmatico, context variabile, multi-agent messaging e uno stato modificabile dal sistema stesso.
