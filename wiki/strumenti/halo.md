# Halo

## Introduzione

Halo è un framework per post-training di modelli open source che mantiene i modelli in formato HuggingFace nativo.

## Capacità

- Fino a 2,8 volte il throughput di TRL con meno memoria di picco.
- Modelli restano in formato HuggingFace nativo.

- **2026-09-22** — Presentato Halo, framework post-training con 2,8x throughput vs TRL e minore memoria, output nativo HuggingFace.
