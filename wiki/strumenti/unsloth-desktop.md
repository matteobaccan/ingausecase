# Unsloth Desktop

## Introduzione

Prima app desktop di Unsloth per eseguire e addestrare modelli localmente: open source, supporta MLX, diffusion e GGUF, collega Claude Code e Codex a LLM locali con tool calls cinquanta percento piu' accurati.

## Funzionalità principali

- Unsloth Desktop e' la prima app desktop per eseguire e addestrare modelli localmente: open source, gira su Mac, Windows e Linux, supporta MLX, diffusion immagini e video, audio e GGUF; connette Claude Code e Codex a LLM locali con tool calls cinquanta percento piu' accurati.
