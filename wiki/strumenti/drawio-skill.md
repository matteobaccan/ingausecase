# drawio-skill

## Introduzione

Skill open source per Claude Code che trasforma intere codebase in diagrammi interattivi con auto-correzione visiva.

## Funzionalità principali

- drawio-skill trasforma intere codebase in diagrammi interattivi senza toccare una coordinata: estrae i moduli, usa Graphviz per il layout ed elimina le connessioni ridondanti; l'agente guarda il PNG finale e autocorregge sovrapposizioni e testo tagliato in cinque iterazioni.
