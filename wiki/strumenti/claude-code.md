# Claude Code

## Introduzione

Strumento di coding di Anthropic: versione due virgola uno virgola duecentoventiquattro con self-hosted runner, edit tool a sostituzione esatta e sessioni che si messaggiano tra loro.

## Funzionalità principali

- Claude Code, abbinato a Claude Opus 4.7, prende il primo posto sul leaderboard Refactoring di Scale AI per la capacità di ristrutturare codice senza rompere il sistema.
- Claude Code è stato usato da Milla Jovovich per co-costruire MemPalace, funziona con spec-kit di GitHub ed è compatibile con rtk, che taglia il 60-90% dei suoi token.
- Claude Code è al centro dei corsi 'Claude Code in Action' delle certificazioni Anthropic ed è supportato dal sistema open source vincitore dell'hackathon Anthropic-Cerebral Valley, insieme a Codex, Cursor, OpenCode e Gemini.
