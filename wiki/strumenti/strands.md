# Strands

## Introduzione

Agent harness general purpose che [[aws]] ha pubblicato come open source, con gestione automatica del contesto, prompt caching e recovery dell'overflow: l'azienda dichiara un consumo di token inferiore di circa il ventotto per cento su sei benchmark.

## Funzionalità principali

- Gestione automatica del contesto, prompt caching e recupero dall'overflow: il bersaglio è il costo operativo degli agenti, cioè la quantità di contesto elaborata durante l'esecuzione.

## Azienda / Autore

- [[aws]]

## Timeline delle notizie

- **2026-09-21** — AWS pubblica come open source Strands, harness per agenti con gestione automatica del contesto, prompt caching e recovery dell'overflow, dichiarando circa il ventotto per cento di token in meno su sei benchmark.
- **2026-09-30** — AWS pubblica Strands Harness, tool open source per costruire agenti IA personalizzati indipendenti dal modello: la famiglia Strands si allarga dal contesto alla costruzione dell'architettura agente.
