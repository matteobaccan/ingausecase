# Multi-Agent AIOps

## Introduzione

Progetto multi-agentivo per l'operations AI: quattro agenti in sequenza (monitoraggio, analisi, autoriparazione, approvazione) che usano algoritmi deterministici dove serve e un LLM solo per il coordinamento.

## Funzionalità principali

- Quattro agenti in sequenza: monitoraggio, analisi, autoriparazione, approvazione.
- Algoritmi deterministici dove serve, LLM solo per coordinamento.
- Disponibile in Python, Java e Go con documentazione completa.
