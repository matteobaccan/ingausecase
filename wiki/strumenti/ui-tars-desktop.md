# UI-TARS Desktop

## Introduzione

Agente desktop di ByteDance che controlla il computer guardando solo i pixel: screenshot, comprensione e azioni come un umano.

## Funzionalità principali

- UI-TARS Desktop di ByteDance è un agente che controlla il computer completo guardando solo pixel: cento percento locale, nessuna API esterna, trentasei punto quattro mila stelle, Apache 2.0; non ispeziona il DOM né usa API di accessibilità: fa screenshot, capisce, muove il mouse e scrive come un umano.
