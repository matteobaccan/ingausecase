# CodeWiki

## Introduzione

Strumento di Google che trasforma repository open source in guide interattive con demo, walkthrough, flowchart e chatbot: NotebookLM per il codice.

## Funzionalità principali

- CodeWiki di Google trasforma un repository open source in una guida interattiva con demo, walkthrough, flowchart e chatbot.
- CodeWiki di Google trasforma qualsiasi repository GitHub in documentazione navigabile: diagrammi di architettura, spiegazioni per ogni modulo, tutorial e chat integrata, gratis.
