# NeMo

## Introduzione

Runtime ufficiale NVIDIA per modelli di riconoscimento vocale, termine di confronto per Nemotron-3.5-ASR.

## Funzionalità principali

- parakeet.cpp produce output identico byte per byte a NeMo, il framework di riferimento di NVIDIA, ma con inferenza C++ più veloce e senza Python.
- Il runtime Nemo ufficiale di NVIDIA è il confronto di Nemotron-3.5-ASR, che risulta due punto cinque volte più veloce con risultati identici.
