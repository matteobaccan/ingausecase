# CodeFlow

## Introduzione

File HTML unico su GitHub che analizza repository complessi producendo un'architettura interattiva, con zero installazione.

## Funzionalità principali

- CodeFlow è un progetto GitHub da quattromilatrecento stelle: un file HTML unico che, incollando un link GitHub, genera un'architettura interattiva in locale con zero installazione e valuta anche l'impatto delle modifiche sui file collegati.
