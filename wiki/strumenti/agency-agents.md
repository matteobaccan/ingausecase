# agency-agents

## Introduzione

Progetto GitHub open source con 144 agenti IA corrispondenti a quasi tutti i lavori del mondo, integrabile con Codex o Claude Code.

## Funzionalità principali

- agency-agents ha creato 144 agenti IA corrispondenti a quasi tutti i lavori del mondo: frontend developer, UI designer, social media manager, sales, data engineer, legal advisor; 60.000 stelle, open source, si integra con Codex o Claude Code e bastano minuti per far girare un team virtuale completo.
- agency-agents su GitHub (ottocentodiecimila stelle) è una biblioteca open source con oltre centoquaranta ruoli agent specializzati: CEO, avvocati, programmatori, product manager e growth hacker con setup profondo, non prompt generici; multi-agent per team virtuali, gratuito.
