# Agent Governance Toolkit

## Introduzione

Toolkit open source di Microsoft per governance delle tool call: policy engine YAML, identity zero-trust, sandbox a quattro livelli e audit log Merkle tamper-evident.

## Funzionalità principali

- Agent Governance Toolkit di Microsoft intercetta ogni tool call prima che parta: policy engine YAML (allow, deny o approvazione umana), identity zero-trust via SPIFFE, DID e mTLS, sandbox esecuzione a quattro livelli, audit log Merkle tamper-evident; copre i dieci rischi OWASP Agentic Top Ten ed è compatibile con LangChain, CrewAI, AutoGen, OpenAI Agents SDK e Semantic Kernel in Python, TypeScript, Go, Rust e .NET.
