# AX

## Introduzione

AX è un orchestratore agente open source di [[google]] per eseguire miliardi di workload autonomi su cluster, descritto come Kubernetes per esecuzioni agente. [Fonte: raw/puntate/ainews20260922.md]

## Funzionalità principali

- Dichiara task agentici con workspace e gateway, esegue sandboxing, cablaggio workspace e isolamento di rete su Agent Substrate. [Fonte: raw/tldr/tldr20260921.md]
- Alto throughput dichiarativo. [Fonte: raw/tldr/tldr20260921.md]

## Timeline delle notizie

- **2026-09-21** — TLDR descrive AX come orchestratore dichiarativo su Agent Substrate per miliardi di workload. [Fonte: raw/tldr/tldr20260921.md]
- **2026-09-22** — Google rilascia AX, orchestratore open source per agenti (Kubernetes per esecuzioni agente). [Fonte: raw/puntate/ainews20260922.md]
- **2026-10-17** — AX di Google, sistema open source per orchestrare miliardi di task agent autonomi, si usa con file YAML e comandi simili a kubectl e permette di sospendere e riprendere gli agent esattamente dove si erano fermati: 13.500 stelle su GitHub, licenza Apache 2.0.
