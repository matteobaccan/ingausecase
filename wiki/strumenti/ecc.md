# ECC

## Introduzione

Estensione open source che aggiunge memoria persistente a Claude Code, con hook che registrano correzioni ed errori e skill permanenti generabili con il comando Evolve. Oltre duecentotrentasettemila stelle.

## Funzionalità principali

- ECC è stato citato tra i dieci repository esplosi della settimana: ottimizzazione della toolchain per agenti AI.
- ECC (Everything Claude Code) ha vinto l'hackathon di Anthropic: prodotto funzionale in otto ore con Claude Code e quindicimila dollari di premio, poi open source; oltre duecentomila stelle e trentamila fork; include sessantasette agenti specializzati, duecentosettantuno skills, comandi slash per automatizzare il flusso, AgentShield con milleduecentoottantadue test di sicurezza, tre agenti Opus quattro punto sei in pipeline red-team e un layer di apprendimento continuo; funziona in Claude Code, Cursor, Codex, OpenCode, Gemini, Zed e GitHub Copilot.
- Sistema vincitore dell'hackathon di Anthropic, supera 210.000 stelle su GitHub: aggiunge 60 agenti, 231 skill, scanner di sicurezza e memoria persistente tra sessioni. Funziona con Claude Code, Cursor, Codex e OpenCode.
