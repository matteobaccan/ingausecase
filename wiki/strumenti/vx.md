# Vx

## Introduzione

Linguaggio di programmazione per il calcolo eterogeneo che mette topologia hardware, collocazione della memoria e raggiungibilità direttamente nel sistema di tipi.

## Funzionalità principali

- Mette topologia hardware, collocazione della memoria e raggiungibilità direttamente nel sistema di tipi.
- Sposta in fase di type checking una classe di bug che normalmente si manifesta come crash a runtime, corruzione silenziosa o errore out-of-memory al passo 1.200 di training.
