# Claude Code dataviz

## Introduzione

Skill slash ufficiale di Claude Code (versione 2.1.198) per la visualizzazione di dati: linee guida di scelta dei grafici, regole layout e validatore palette colori eseguibile.

## Funzionalità principali

- Nuovo skill ufficiale di Claude Code 2.1.198: la slash command dataviz carica linee guida per selezione tipo grafico, regole layout e gerarchia visiva per interfacce ricche di dati, con un validatore palette colori eseguibile per controllare contrasto e accessibilità programmaticamente.
