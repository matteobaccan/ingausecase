# DeepGEMM

## Introduzione

Libreria open source di [[deepseek]] che accelera i calcoli GPU dietro i modelli IA: ottimizza i calcoli matriciali che alimentano i large language model, compila kernel a runtime ed è rilasciata con licenza MIT.

## Funzionalità principali

- Supporta FP8, FP4 e BF16 e ottimizza i workload per mixture-of-experts, sovrapponendo comunicazione e computazione GPU. [Fonte: raw/puntate/ainews20261002.md]
- Compila kernel a runtime ed è distribuita come open source con licenza MIT. [Fonte: raw/puntate/ainews20261002.md]
