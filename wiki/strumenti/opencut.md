# OpenCut

## Introduzione

Editor video open source web con multi-track timeline, cinquantaduemila stelle, core in riscrittura Rust per supporto MCP e agenti.

## Funzionalità principali

- OpenCut è il clone open source dell'intera app CapCut: 45.800 stelle in meno di un anno, licenza MIT, niente watermark, niente abbonamenti, e le clip non lasciano mai il dispositivo.
- OpenCut è un editor video open source con cinquantaduemila stelle: zero abbonamenti, zero watermark, zero tracking; multi-track timeline, editing frame-perfect, anteprima real-time, keyframe animation e transizioni; il core è in riscrittura Rust per MCP e AI Agent di montaggio automatico.
- OpenCut è una copia open source di CapCut: editing video senza watermark, senza subscription e senza funzioni bloccate, con oltre cinquantacinquemila e quattrocento stelle; compatibile con web, desktop e mobile.
