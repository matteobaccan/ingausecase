# Agent Reach

## Introduzione

CLI che migliora la ricerca web degli agenti IA evitando API a pagamento, blocchi, login e cookie, selezionando automaticamente la migliore opzione per piattaforma. Sessantanovemila stelle.

## Funzionalità principali

- Agent Reach ha ventuno punto sette mila stelle: raccoglie dati da quindici piattaforme social senza costi API, basato su strumenti open source con installazione automatica via agente.
- Agent Reach legge sedici piattaforme tra X, YouTube, GitHub, Reddit e LinkedIn: trascrizioni, post e repository accessibili da Claude Code e Cursor; ventiquattromilaquattrocento stelle.
- Agent Reach ha ventisei punto quattro mila stelle: permette ad agenti come Claude Code, Cursor o OpenClaw di accedere a YouTube, GitHub, Twitter, Reddit e Xiaohongshu senza API a pagamento, gestendo automaticamente yt-dlp, GitHub CLI e altri strumenti; installazione con una sola riga di comando.
