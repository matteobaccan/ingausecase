# QVAC SDK

## Introduzione

SDK software (versione 0.13.0) che aggiunge integrazione diretta con gli agenti di coding e supporto per modelli vision-language robotici.

## Funzionalità principali

- QVAC SDK 0.13.0 aggiunge integrazione diretta con gli agenti di coding come opencode e altri framework, con nuovo supporto per pi0.5, modello vision-language per robotica.
