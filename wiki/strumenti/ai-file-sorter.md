# AI File Sorter

## Introduzione

Strumento che rinomina file generici con titoli descrittivi e organizza directory disordinate usando modelli linguistici locali o remoti.

## Funzionalità principali

- Rinomina dei file con titoli descrittivi.
- Organizzazione automatica delle directory.
- Supporto a modelli linguistici locali o remoti.
