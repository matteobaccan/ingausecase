# Playwright

## Introduzione

Framework open source di automazione browser di Microsoft, base dell'aggiornamento agentico Webwright.

## Funzionalità principali

- Playwright è stato citato come base di Webwright, l'aggiornamento Microsoft che rende ogni sessione un workflow riutilizzabile per agenti.

## Timeline delle notizie

- **2026-02-03** — Playwright MCP di Microsoft dà occhi all'AI che scrive codice: apre un browser reale, compila form, mantiene sessioni autenticate e cattura screenshot a ogni azione, con self-healing locators, confronto pixel-perfect (maxDiffPixels, maxDiffPixelRatio) e l'AI Healer che ripara da solo i test rotti con un tasso di successo dichiarato oltre il 75%; dal 2026 il browser di default è Chrome for Testing al posto di Chromium. La versione Microsoft usa snapshot di accessibilità per CI/CD, quella di ExecuteAutomation punta sugli screenshot visivi per il debugging interattivo.
