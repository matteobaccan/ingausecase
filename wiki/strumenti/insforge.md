# InsForge

## Introduzione

Backend open source strutturato per agenti, non per dashboard, self-hostable via Docker. Ha dimostrato tagli dell'uso di token fino a 2,5 volte.

## Funzionalità principali

- InsForge riduce l'uso token di Fable 5 di due punto cinque volte: da cinque punto cinque milioni di token e otto dollari novantaquattro a due punto tre milioni e quattro dollari diciassette; topologia completa del backend in una chiamata CLI da cinquecento token (auth, database, storage, edge function, model gateway, micro VM), JSON strutturato con exit code significativi; open source e Docker.
- Un developer ha ridotto l'uso di token di Fable 5 di 2,5 volte passando da Firebase a InsForge: da 5,5 milioni di token (8,94 dollari) a 2,3 milioni (4,17 dollari). Backend strutturato per agenti, open source, self-hostable via Docker.
