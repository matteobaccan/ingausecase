# MaxHermes

## Introduzione

Versione cloud di Hermes Agent di MiniMax, framework IA open source auto-evolutivo con oltre 130.000 stelle GitHub, powered by MiniMax M2.7, integrabile con Telegram, Discord, Slack, WhatsApp, Signal ed email.

## Funzionalità principali

- MaxHermes è la versione cloud di Hermes Agent di MiniMax, l'open source framework IA con oltre 130.000 stelle GitHub: stesso motore auto-evolutivo ma con zero setup, live in dieci secondi, ogni task complesso diventa skill permanente, vive dove sei già (Telegram, Discord, Slack, WhatsApp, Signal, email), powered by MiniMax M2.7.
