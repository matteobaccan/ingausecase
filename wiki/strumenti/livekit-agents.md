# LiveKit Agents

## Introduzione

Framework open source per agenti vocali real-time: WebRTC audio-video, telefonate in entrata e uscita, rilevamento turni semantico e MCP tool calling nativo.

## Funzionalità principali

- LiveKit Agents e' un framework open source per agenti vocali real-time: WebRTC audio-video, telefonate in e out, rilevamento turni semantico, MCP tool calling nativo, multi-agent handoff e test con LLM Judge integrati, stack completo self-hosted.
