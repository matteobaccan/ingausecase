# ja-furigana

## Introduzione

Tool che assegna letture corrette al giapponese guardando il contesto, con server HTTP per integrazioni TTS.

## Funzionalità principali

- ja-furigana assegna letture corrette al giapponese guardando il contesto: distingue ichinichibshochō da altri composti e ashita per domani; server HTTP per integrazioni con TTS.
