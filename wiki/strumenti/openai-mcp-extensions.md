# OpenAI MCP Extensions

## Introduzione

Progetto di [[openai]] con licenza Apache che integra plugin esterni come funzioni native di [[chatgpt]].

## Funzionalità principali

- Integra plugin esterni come funzioni native di ChatGPT: ingresso in sidebar, visualizzatori dedicati per i file, ricerca dei contenuti e form con scelte a miniature.
- SDK in TypeScript e Python.
- Circa 789 stelle su GitHub.
