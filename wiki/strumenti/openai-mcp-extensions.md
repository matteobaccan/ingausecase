# OpenAI MCP Extensions

## Introduzione

Progetto di [[openai]] con licenza Apache che integra plugin esterni come funzioni native di [[chatgpt]]. [Fonte: raw/puntate/ainews20261011.md]

## Funzionalità principali

- Integra plugin esterni come funzioni native di ChatGPT: ingresso in sidebar, visualizzatori dedicati per i file, ricerca dei contenuti e form con scelte a miniature. [Fonte: raw/puntate/ainews20261011.md]
- SDK in TypeScript e Python. [Fonte: raw/puntate/ainews20261011.md]
- Circa 789 stelle su GitHub. [Fonte: raw/puntate/ainews20261011.md]
