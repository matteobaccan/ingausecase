# Public APIs

## Introduzione

Repo open source che raccoglie 1.500 endpoint gratuiti organizzati per categoria, con 435.000 stelle.

## Funzionalità principali

- Public APIs raccoglie 1.500 endpoint gratuiti organizzati per categoria (finanza, cripto, clima, mappe, musica, film, machine learning, OCR, dati governativi, salute) con autenticazione, CORS, HTTPS e documentazione per ogni entry: 435.000 stelle, MIT license, e metà dei tool da 99 dollari al mese wrappano endpoint di questo repo.
