# DeepSeek Bot

## Introduzione

Plugin open source non ufficiale basato su [[deepseek-harness]] che permette di creare bot persistenti con la propria API key.

## Funzionalità principali

- Crea bot persistenti con la propria API key.
- Collega qualsiasi modello o agente locale.
- Eredita l'architettura "tutto è plugin" di DSH.

## Azienda / Autore

- [[deepseek]]

## Timeline delle notizie

- **2026-10-11** — DeepSeek Bot è un plugin open source non ufficiale basato su DeepSeek Harness: crea bot persistenti con la propria API key, collega qualsiasi modello o agente locale ed eredita l'architettura "tutto è plugin" di DSH.
- **2026-10-28** — Il plugin non ufficiale per [[deepseek-harness]] supera le 4.326 stelle a tre settimane dal debutto e arriva alla 0.2.3: ogni bot ha nome, ruolo, modello assegnato e memoria in Markdown che il modello aggiorna da sé, la pagina Usage conta i token per bot e per modello e in ogni chat di gruppo un amministratore risponde di norma e chiama gli altri con la @. Le versioni di fine ottobre aggiungono l'app desktop con una copia di DSH per Windows, macOS e Linux, il comando /btw per interrogare un bot mentre lavora, un profilo Playwright per bot con gli accessi mantenuti e la barra di sistema che tiene l'app attiva a finestra chiusa. È un progetto indipendente non affiliato a DeepSeek, con licenza Apache 2.0 e ancora in anteprima 0.2.
