# Rowboat

## Introduzione

Alternativa locale gratuita a Claude Cowork: si connette a Gmail e note meeting, costruisce un knowledge graph del lavoro e agisce; voice-enabled e MCP-estendibile, con vault Markdown compatibile Obsidian.

## Funzionalità principali

- Rowboat è l'alternativa locale gratuita a Claude Cowork: si connette a Gmail e note meeting, costruisce un knowledge graph del tuo lavoro e agisce; è voice-enabled, compatibile con qualsiasi LLM locale o hosted, estendibile con MCP tool, con background agent, web search e vault Markdown compatibile Obsidian; 14300 stelle.
