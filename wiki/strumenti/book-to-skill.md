# book-to-skill

## Introduzione

Strumento che estrae skill da PDF, EPUB, DOCX e Markdown generando SKILL punto md con core model, capitoli, termini e metodi; riduzione token di ventiquattro-cinquantuno volte.

## Funzionalità principali

- book-to-skill trasforma PDF ed EPUB in skill per Claude Code: seimila stelle, estrazione automatica dei concetti chiave e generazione di file riutilizzabili per interrogare il contenuto dei libri.
- book-to-skill converte libri in skill per Claude: invece di caricare l'intero libro, la skill consulta capitolo per capitolo; diciassettemila stelle su GitHub.
- book-to-skill estrae skill da PDF, EPUB, DOCX e Markdown: genera SKILL punto md con core model, capitoli, termini e metodi, con riduzione token di ventiquattro-cinquantuno volte; funziona con Claude Code, Copilot CLI, Amp e Codex con adattamenti.
