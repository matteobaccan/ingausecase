# LangGraph

## Introduzione

Framework per la costruzione di agenti IA basati su grafi, appartenente all'ecosistema LangChain. Trasforma workflow frammentati in grafi verificabili.

## Funzionalità principali

- LangGraph è citato tra i framework con cui funziona Memanto per dare memoria infinita agli agenti IA.
- LangGraph è stato segnalato tra i repository GitHub per l'automazione di workflow con AI, per l'orchestrazione in produzione.
- LangGraph ha raggiunto trentottomila stelle su GitHub: trasforma workflow IA frammentati in grafi verificabili che controllano, ritentano ed escalano prima che un errore comprometta tutto.
