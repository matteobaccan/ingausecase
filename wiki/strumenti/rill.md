# Rill

## Introduzione

Piattaforma open source di dashboard definite in YAML e SQL, con server MCP integrato per connettere Claude, ChatGPT e altri agenti al layer metrico.

## Funzionalità principali

- Rill permette dashboard definite in YAML e SQL con server MCP integrato: Claude, ChatGPT o agenti si collegano direttamente al layer metrico; licenza Apache 2.0.
