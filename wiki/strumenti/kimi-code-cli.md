# Kimi Code CLI

## Introduzione

Alternativa open source gratuita a Claude Code del team Kimi: upload di registrazioni schermo, agenti separati per coding, planning e ricerca.

## Funzionalità principali

- Kimi Code CLI è un'alternativa open source gratuita a Claude Code: upload di registrazioni schermo, agenti separati per coding, planning e ricerca, pianifica le modifiche prima di toccare i file, setup MCP diretto da CLI, compatibile con VS Code, JetBrains e Zed, avvio in secondi senza Node.js.
- Kimi Code CLI è open source con licenza MIT: registra lo schermo e trasforma il video in istruzioni dirette, con modalità coder, explore e plan separate, ogni file pianificato prima di essere toccato, nessuna dipendenza Node e avvio istantaneo.
- Moonshot AI ha rilasciato Kimi Code CLI: agente da terminale basato su Kimi K3 con supporto a input video e sub-agenti dedicati. Open source.
