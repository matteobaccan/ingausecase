# OSINT Mapping Tool

## Introduzione

Organizza la ricerca OSINT nel browser con nodi collegati a geolocalizzazione, dati salvati in JSON locale.

## Funzionalità principali

- OSINT Mapping Tool organizza la ricerca intelligence open source nel browser: nodi per account social, telefoni e veicoli collegati a geolocalizzazione, con Google Maps e OpenStreetMap; dati salvati in JSON locale, React 18 più Vite, nessun upload.
