# SkillSpector

## Introduzione

Strumento open source di NVIDIA per rilevare vulnerabilità nelle skill degli agenti AI.

## Funzionalità principali

- SkillSpector di NVIDIA rileva vulnerabilità nelle skill degli agenti: blocca prompt injection, esfiltrazioni dati, dipendenze vulnerabili e codice pericoloso.
