# OpenWiki

## Introduzione

Strumento di LangChain con quattordicimila stelle che genera e aggiorna documentazione per codebase, con chat con la wiki e Git action quotidiana.

## Funzionalità principali

- OpenWiki salva automaticamente testo, immagini o link copiati: l'AI riorganizza tutto, crea wiki e mappe di conoscenza; dati locali, export Markdown e supporto MCP.
- Tool per creare e mantenere documentazione di progetti: crea PR automatiche per aggiornamenti continui, compatibile con OpenAI, Claude e OpenRouter. Open source.
- openwiki di LangChain ha quattordicimila stelle: un comando genera e aggiorna documentazione per codebase, Git action per aggiornamento quotidiano, interfaccia chat per parlare con la wiki e injection in Agent punto md per conoscenza progetto automatica.
