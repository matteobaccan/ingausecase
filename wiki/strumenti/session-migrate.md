# session-migrate

## Introduzione

Strumento per migrare le sessioni di coding agent tra diversi ambienti con un singolo comando.

## Funzionalità principali

- session-migrate migra le sessioni di coding agent tra Claude Code, Codex, Pi, OpenCode e altri: un comando converte la sessione da un ambiente all'altro.
