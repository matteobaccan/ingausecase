# Anthropic Cybersecurity Skills

## Introduzione

Set di 754 skill di cybersecurity mappate su cinque framework (MITRE ATT&CK, NIST CSF, D3FEND, ATLAS, AI RMF), compatibile con Claude, Copilot, Cursor, Codex e Gemini.

## Funzionalità principali

- Sono comparse su GitHub 754 skill di cybersecurity mappate su cinque framework (MITRE ATT&CK, NIST CSF, D3FEND, ATLAS, AI RMF): una base di conoscenza per dare agli agenti AI workflow di sicurezza reali invece di risposte generiche, compatibile con Claude, Copilot, Cursor, Codex e Gemini; il progetto (Anthropic-Cybersecurity-Skills) è tra i dieci repository esplosi della settimana.
