# Stirling-PDF

## Introduzione

Alternativa open source ad Adobe Acrobat con oltre 50 strumenti PDF, OCR, API REST e Docker, 81K stelle.

## Funzionalità principali

- Stirling-PDF è l'alternativa open source ad Adobe Acrobat: oltre cinquanta strumenti per manipolare PDF, OCR integrato, supporto API REST e compatibilità Docker, tutto eseguibile su server locale; supera gli 81.000 stelle su GitHub.
