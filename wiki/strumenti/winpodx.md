# WinPodX

## Introduzione

Progetto open source che esegue applicazioni Windows su Linux tramite container con rendering remoto delle app.

## Funzionalità principali

- WinPodX è un progetto open source che permette di eseguire applicazioni Windows su Linux: doppio clic su un file .docx e si apre con Word, appunti, audio e stampanti condivisi bidirezionalmente, USB passato direttamente a Windows; funziona tramite container con rendering remoto delle app, installazione in una riga e supporto alle principali distribuzioni Linux.
