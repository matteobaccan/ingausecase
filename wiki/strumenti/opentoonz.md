# OpenToonz

## Introduzione

Software di animazione 2D utilizzato da Studio Ghibli (Chihiro, Totoro, Mononoke), open source dal 2016 con licenza BSD-3, versione di produzione completa del team.

## Funzionalità principali

- OpenToonz è il software di Studio Ghibli usato per Il viaggio di Chihiro, Totoro e Mononoke: dal 2016 è open source nella versione di produzione completa con le personalizzazioni originali del team, zero costi e licenza BSD-3, mentre Toon Boom Harmony costa 1575 dollari l'anno.
