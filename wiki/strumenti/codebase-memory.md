# codebase-memory

## Introduzione

Strumento che trasforma un'intera codebase in un grafo di funzioni, file e dipendenze per ridurre i token usati da agenti su query strutturali.

## Funzionalità principali

- Indicizza il kernel Linux (28 milioni di righe) in 3 minuti e un repo in secondi. Dieci volte meno token su query strutturali, 83% di qualità su task complessi, 2,1 volte meno chiamate tool. Benchmarkato su 31 repo reali.
- Indicizza il kernel Linux completo in 3 minuti e crea un grafo di conoscenza del repository: riduce il consumo di contesto del 99%. Oltre 24.000 star su GitHub.
