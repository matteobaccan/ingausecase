# METATRON

## Introduzione

Assistente locale per penetration testing su GitHub che combina strumenti di scansione e un modello locale, senza bisogno di API key.

## Funzionalità principali

- Combina Nmap, WhatWeb, WHOIS, DNS, Nikto e un modello locale per il penetration testing. [Fonte: raw/puntate/ainews20260906.md]
- Genera report in PDF e HTML senza API key e gira interamente in locale. [Fonte: raw/puntate/ainews20260906.md]
