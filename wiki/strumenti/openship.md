# OpenShip

## Introduzione

Piattaforma open source per creare il proprio stack Vercel, Supabase e mail server su VPS, con deploy di app e database.

## Funzionalità principali

- OpenShip permette di creare il proprio Vercel, Supabase e mail server su VPS: deploy di app, database e backup, alternativa open source a Dokploy e Coolify.
