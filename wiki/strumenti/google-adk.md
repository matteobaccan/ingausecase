# Google ADK 2.0

## Introduzione

Agent Development Kit di Google, framework open source per agenti con grafo, routing e human-in-the-loop, in sostituzione di LangChain e Vertex AI Agent Builder.

## Funzionalità principali

- Google ADK 2.0 è il framework open source per agenti di Google: grafo, routing, fan-out, loop, retry, stato e human-in-the-loop, con CLI interattiva e Web UI; sostituisce LangChain, LangGraph e Vertex AI Agent Builder, zero vendor lock-in.
