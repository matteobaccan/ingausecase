# Isaac GR00T Reference Humanoid Robot

## Introduzione

Primo design di riferimento robotico umanoide open di NVIDIA per la ricerca, che combina hardware Unitree e Sharpa con software Isaac GR00T.

## Funzionalità principali

- NVIDIA Isaac GR00T Reference Humanoid Robot combina il robot Unitree H2, le mani Sharpa Robotics Wave a cinque dita, il calcolo onboard Jetson Thor e il software e modelli open Isaac GR00T, come primo design di riferimento per la ricerca robotica.
