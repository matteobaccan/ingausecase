# Nova3D

## Introduzione

Strumento che genera modelli 3D con ogni parte selezionabile: produce script Blender Python con componenti nominati e materiali modificabili.

## Funzionalità principali

- Nova3D genera modelli 3D con ogni parte selezionabile: prompt in ingresso, script Blender Python in uscita, ogni componente con nome, gerarchia e materiale modificabile, niente mesh unico ingestibile.
