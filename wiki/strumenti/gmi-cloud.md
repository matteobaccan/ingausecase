# GMI Cloud

## Introduzione

Piattaforma che offre accesso API per modelli MiniMax con un generoso credito di token gratuito, senza pagamento anticipato.

## Funzionalità principali

- GMI Cloud offre due miliardi di token gratuiti per MiniMax M3 e MiniMax 2.7 per i prossimi quattordici giorni, con accesso API senza pagamento anticipato.
