# Pinchtab

## Introduzione

Binario da 12 MB che fornisce controllo completo del browser via API HTTP, con modalità stealth e sessioni persistenti.

## Funzionalità principali

- Pinchtab è un binario da dodici megabyte che fornisce controllo completo del browser via API HTTP: gestisce istanze Chrome dedicate, espone un albero DOM stabile, supporta modalità stealth per bypassare il rilevamento bot e mantiene sessioni persistenti, con dashboard in tempo reale incluso.
