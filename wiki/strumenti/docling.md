# Docling

## Introduzione

Convertitore open source di Firecrawl scritto in Rust: trasforma quattordici formati office in Markdown pulito in stile GitHub, ottimale per i LLM.

## Funzionalità principali

- Docling di Firecrawl converte quattordici formati office in Markdown pulito in output GitHub style, scritto in Rust e perfetto per i LLM.
