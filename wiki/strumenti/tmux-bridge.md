# tmux-bridge

## Introduzione

Progetto che permette a Claude Code, Codex, Gemini CLI e Kimi Code di leggere reciprocamente i terminali e collaborare via MCP.

## Funzionalità principali

- Il progetto tmux-bridge permette a Claude Code, Codex, Gemini CLI e Kimi Code di leggere reciprocamente i terminali e collaborare tramite MCP, eliminando la necessità di aprire più finestre terminal.
