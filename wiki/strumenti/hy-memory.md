# Hy-Memory

## Introduzione

Plugin open source di Tencent Hunyuan che dà memoria a lungo termine agli agenti collaborativi, il 'Secondo Cervello' del tuo agente.

## Funzionalità principali

- Hy-Memory è un plugin di memoria open source di Tencent Hunyuan per agenti come OpenClaw, basato su framework a sei layer con sistema uno/sistema due e catena evolutiva a tre layer: oltre settanta percento di memorie in meno, oltre quarantacinque percento più densità informativa, trentacinque percento meno token su contesti ultra-lunghi e venti percento più veloce negli aggiornamenti.
