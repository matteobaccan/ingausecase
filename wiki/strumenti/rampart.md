# RAMPART

## Introduzione

Framework di test pytest di Microsoft per agenti AI: attacchi adversarial, categorie di harm ed evaluation basata su assertion, nativamente pytest.

## Funzionalità principali

- RAMPART di Microsoft è un framework pytest per testare agenti AI: copre attacchi adversarial, failure mode benigni e categorie di harm con assertion-based evaluation, 100% pytest-native e integrabile nella suite esistente.
