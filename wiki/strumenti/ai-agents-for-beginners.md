# AI Agents for Beginners

## Introduzione

Corso gratuito e open source di [[microsoft]] per imparare a costruire agenti AI, con settantaduemila stelle su GitHub. [Fonte: raw/puntate/ainews20260928.md]

## Funzionalità principali

- Diciotto unità che coprono tool calling, Agentic RAG, pianificazione, multi-agent, memoria, deployment e sicurezza. [Fonte: raw/puntate/ainews20260928.md]
- Ogni lezione include tutorial, video brevi e codice Python. [Fonte: raw/puntate/ainews20260928.md]
- Compatibile con GitHub Models, Azure AI Foundry e interfacce OpenAI. [Fonte: raw/puntate/ainews20260928.md]
