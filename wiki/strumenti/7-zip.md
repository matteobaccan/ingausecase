# 7-Zip

## Introduzione

Software di compressione file open source, colpito dalla vulnerabilità CVE-2026-14266 che consente esecuzione di codice remoto.

## Funzionalità principali

- Occhio alla vulnerabilità CVE-2026-14266 in 7-Zip: la gestione impropria dei dati XZ può causare buffer overflow e permettere l'esecuzione di codice remoto, aggiornare immediatamente.
