# Prompt per Agent-Ergonomia

## Introduzione

Insieme di prompt per progettazione agent-ergonomica: un sistema sintetico massimamente coerente, coeso, modulare e interconnesso, con una torre di astrazioni linkate leggibili per agenti.

## Evoluzione nel tempo

- Sistema sintetico massimamente coerente, coeso, modulare, interconnesso.
- Torre di astrazioni linkate leggibili per agenti.

## Timeline delle notizie

- **2026-09-01** — Prompt per progettazione agent-ergonomica: sistema sintetico massimamente coerente, coeso, modulare, interconnesso. Torre di astrazioni linkate leggibili per agenti.

- **2026-09-12** — OpenAI codifica il principio opposto a quello che il settore ha seguito per un anno: con [[gpt-6-astra]] conviene **togliere** istruzioni dai prompt, perché il modello lancia i test da solo ed è più sensibile al contesto, quindi un vincolo scritto per un modello meno accorto diventa rumore o un blocco inatteso. La guida *Rethinking skills and prompts for GPT-6 Astra* indica descrizioni delle skill con trigger precisi, progressive disclosure per le skill lunghe, AGENTS.md trasformati da imperativi assoluti in mappe, confini decisionali più larghi con un bias verso l'azione e la definizione anticipata di cosa significa "finito".
- **2026-10-10** — La guida ufficiale di OpenAI al prompt engineering raccomanda di marcare le sezioni con intestazioni e liste Markdown e di delimitare i contenuti incollati con tag XML, usando attributi come id="esempio-1" per richiamare gli esempi per nome; l'ordine consigliato dei blocchi è Identity, Instructions, Examples, Context, con il contenuto variabile in coda per sfruttare la cache dei prompt. Nella documentazione attuale non esiste alcun elenco di simboli speciali: le triple virgolette non compaiono più e il triplo cancelletto è un'indicazione di guide non ufficiali, mentre i comandi veri restano i ruoli dei messaggi developer e user, che decidono quale istruzione prevale.
