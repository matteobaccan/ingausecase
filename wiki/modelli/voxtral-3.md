# Voxtral 3

## Introduzione

Famiglia di modelli per la trascrizione e la sintesi vocale di [[mistral]], lanciata il 21 ottobre 2026 come motore della nuova API per voice agent dell'azienda.

## Capacità e performance

- Copre trascrizione e sintesi vocale e alimenta la nuova API per voice agent.
- È presentata come pensata per dare risposte rapide senza perdere precisione.
