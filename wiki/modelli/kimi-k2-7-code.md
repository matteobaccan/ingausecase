# K2.7-Code

## Introduzione

Modello di coding della famiglia Kimi K2.7 di Moonshot AI, disponibile tramite abbonamenti aggregati come ClinePass.

## Capacità e performance

- K2.7-Code registra un aumento del ventuno punto otto percento su Kimi Code Bench versione due e del trentuno punto cinque percento su MLS Bench Lite rispetto alla versione precedente, consumando il trenta percento in meno di token durante il ragionamento.
- Kimi K2.7 Code ha superato la versione precedente nei test su sistemi solari, attrattori di Lorenz e onde d'acqua, con un rendering molto più realistico: le onde sembrano finalmente onde.
- La nuova modalità high-speed di Kimi K2.7 Code è sei volte più veloce: centottanta token al secondo su task di coding e duecento sessanta token al secondo su contesti brevi; Unsloth ha reso il modello eseguibile in locale, compresso da un terabyte a trecentoventicinque gigabyte, con quaranta token al secondo su configurazioni da trecentotrenta gigabyte di RAM o VRAM.
