# ChatGPT Image 2.0

## Introduzione

Modello di generazione immagini di OpenAI, usato nel flusso 'foto e prompt a sito pronto' insieme a Claude Opus 4.6.

## Capacità e performance

- ChatGPT Images 2.0 più GPT-5.5 Codex trasformano render di prodotto in CAD direttamente nel terminale Codex con ForgeCAD: niente software di modellazione, immagine entra e CAD model esce in decine di secondi in sessione singola.
- ChatGPT Image 2.0 genera il design del sito: poi si passa tutto a Claude Opus 4.6 che lo trasforma in codice funzionante; una foto e un prompt bastano per un sito pronto.
