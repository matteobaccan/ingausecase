# Qwen3.7-Plus

## Introduzione

Modello multimodale agent di Alibaba che unifica visione e linguaggio con operazione GUI e CLI unificata.

## Capacità e performance

- Qwen3.7-Plus unifica visione e linguaggio in una base agente versatile: agente GUI/CLI ibrido, coding agent e assistente di produttività full-modality, Visual Agent con percezione, ragionamento, grounding e QA search-augmented; disponibile via API su Alibaba Cloud Model Studio.
