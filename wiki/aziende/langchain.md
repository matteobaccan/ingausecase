# LangChain

## Introduzione

Framework open source per applicazioni LLM e pipeline RAG, integra OpenDataLoader PDF ed è compatibile con Agent-Reach.

## Timeline delle notizie

- **2026-05-27** — LangChain è stato citato come framework compatibile con Agent Governance Toolkit di Microsoft per la governance delle tool call.
- **2026-06-02** — OpenDataLoader ha un'integrazione ufficiale LangChain per il parsing di PDF in Markdown a cento pagine al secondo.
- **2026-06-15** — LangChain ha integrazione nativa con OpenDataLoader PDF per pipeline RAG ed è citato tra i framework compatibili con Agent-Reach.
- **2026-08-08** — LangChain ha rilasciato openwiki, con quattordicimila stelle: un comando genera e aggiorna documentazione per le codebase, con Git action per aggiornamento quotidiano, interfaccia chat per parlare con la wiki e injection in Agent punto md.

- **2026-09-25** — LangChain ha rilasciato Managed Deep Agents 0.8, che aggiunge supporto alle credenziali di proprietà dell'utente, memoria a livello utente, canali HTTP e trasferimento file in Slack, più uno strumento pre-costruito per la ricerca web basato su Parallel.
- **2026-10-02** — LangChain sperimenta un model router integrato nell'harness del proprio coding agent Open SWE per evitare di usare il modello più costoso su ogni richiesta: in un test di produzione su 973 thread il router ha assegnato i task a tre livelli di modello sulla base del primo messaggio dell'utente, con il 56% sul livello bilanciato, il 34% su quello rapido e solo il 10% sul livello più potente.
