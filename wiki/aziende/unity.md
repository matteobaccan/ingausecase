Azienda del motore di gioco Unity. Ha rilasciato uno strumento CLI gratuito per gamedev con IA.

## Timeline delle notizie

- **2026-08-07** — Unity ha rilasciato uno strumento CLI gratuito per gamedev con IA: gli agenti eseguono codice C# direttamente nell'editor live tramite Roslyn senza ricompilazione, e Kimi K3 ha generato giochi completi con un solo prompt. [Fonte: raw/puntate/ainews20260807.md]
- **2026-09-10** — UnityMCP versione quattro punto uno taglia i consumi di contesto e accelera le risposte: consumo token dal trentasei al novantadue percento, latenza da centotrenta millisecondi a dieci virgola uno, turno fisso da trentamilanovecentosettantatré a duemilacentocinquantaquattro token. È anche disponibile il plugin ufficiale Unity per Claude Code: ventinove skill native Unity al lancio, supporto CLI e controllo diretto dell'Editor. [Fonte: raw/puntate/ainews20260910.md]

- **2026-09-15** — Il plugin ufficiale Unity per Claude Code, con skill dedicati, Unity CLI e server MCP, permette all'IA di gestire operazioni dell'Editor e ottimizzazioni UI, 2D e URP seguendo gli standard ufficiali Unity. [Fonte: raw/puntate/ainews20260915.md]
- **2026-10-09** — Unity presenta Unity Spark, editor di giochi con l'AI in beta chiusa, che si integrerà con Google Playground e si collegherà all'Asset Store di Unity per le risorse grafiche; il CEO Matt Bromberg ha preso le distanze dall'idea del gioco finito con un solo prompt. [Fonte: raw/pillitteri/pillitteri20261009-google-playground-videogiochi-ai-prompt.md]
- **2026-10-20** — Dopo Epic, Unity rilascia il proprio plugin ufficiale per Claude Code con 32 skill per lavorare dentro il progetto: acquisti in-app, video ads, multiplayer, chat vocale Vivox, navigazione AI, fisica 2D e 3D e localizzazione, scelte in linguaggio naturale. [Fonte: raw/puntate/ainews20261020.md]
