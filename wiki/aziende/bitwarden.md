# Bitwarden

## Introduzione

Azienda di password manager open source, colpita dalla supply chain attack di TeamPCP.

## Strumenti

- [[1password]]

## Timeline delle notizie

- **2026-05-21** — Bitwarden è stata colpita dal malware auto-propagante di TeamPCP; nella compromissione di GitHub l'estensione infetta rubava token anche da 1Password. [Fonte: raw/puntate/ainews20260521.md]
- **2026-06-01** — Bitwarden è stato indicato come alternativa open source gratuita a 1Password per la gestione delle password. [Fonte: raw/puntate/ainews20260601.md]
