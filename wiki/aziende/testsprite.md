# TestSprite

## Introduzione

Azienda di testing automatico per agenti di coding, CLI open source Apache 2.0.

## Timeline delle notizie

- **2026-06-13** — TestSprite ha rilasciato la CLI come open source Apache 2.0: permette agli agenti di coding di testare le app end-to-end come utenti reali, correggere errori e riverificare tutto; sul leaderboard pubblico l'app più corretta è stata costruita dal modello più economico, a metà del costo del più costoso.
